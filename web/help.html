使い方

まず「1. アプリのカレンダーを使う設定」をします(区所を選んで、保存するだけです)。 そのあとは、勤務を入力して「保存」を押すだけで、アプリのカレンダーで見られます。
Googleカレンダーとの連携(5.)は、勤務を、アプリ以外のカレンダー(スマホの標準カレンダー・Googleカレンダー・TimeTree など)や家族に同期したいときだけ必要です。アプリのカレンダーだけで使うなら、読まなくて大丈夫です。
1. アプリのカレンダーを使う設定 2. 勤務を入力する 3. shiftflowカレンダー(アプリ内のカレンダー) 4. ホーム画面に追加する(おすすめ) 5. Googleカレンダーとの連携 5-A. スマホで設定する 5-B. パソコンで設定する 5-C. スマホのカレンダーアプリで見る設定 5-D. 登録される予定・接続テストが失敗したとき 6. こまったとき
1. アプリのカレンダーを使う設定(区所を選ぶ・表記を選ぶ・保存)

勤務入力で保存した勤務を、アプリの中のカレンダー(shiftflowカレンダー)で見るための設定です。Googleカレンダーは使いません(これから使い始める人は、最初からこの状態です)。最初の1回だけ行います(1〜2分)。

  1. 上のメニューの「設定」を開く
  2. 区所を選ぶ: 「1. 区所を選ぶ」で、自分の区所を選ぶ(番号の一覧は、区所ごとに違います)
  3. カレンダーの表記を選ぶ: 「カレンダーの表記」のチェックを、使いたいものだけ入れる(何も入れなくても使えます。下の「表記の選び方」を見てください)
  4. 「Googleカレンダーにも登録する」は、チェックなしのままにする(アプリのカレンダーだけで使うなら、これで十分です。他のカレンダーアプリ・家族に同期したい人だけ、下の「5. Googleカレンダーとの連携」へ)
  5. いちばん下の「保存」を押す。「保存済みです」と出れば完了です。「勤務入力へ進む →」を押すと、勤務入力に進めます

次は、「2. 勤務を入力する」で番号を入れて「保存」を押すと、上のメニューの「カレンダー」で見られます。

非番を2段で出す

設定の「非番を2段で出す」にチェックを入れると、非番の日が2段になります。上が「〜」、下が退勤の時間(例: 9:02)です。アプリのカレンダーでは、帯が2本になり、下の帯は「非番」のラベル(別のボタン・別の色)になります。Googleカレンダーにも登録する人は、Googleカレンダーにも、終日の「〜」(メモに退勤時間)と、時間つきの予定の2つが入ります。

2
〜
9:02
  • 下の段の時間は、退勤時間(Googleカレンダーでは、そこから1時間の予定)です。名前は時間だけです
  • 泊の翌日の非番の他、「〜」「-」「非番」「明け」などを手入力した日も、メモに退勤時間(例: 9:02、〜9:02)を書けば2つになります(「公休」「年休」など休みの手入力は1つのままです)

予定の名前に時間を付ける

設定画面の「出勤の予定の名前に出勤時間を付ける」「非番の予定の名前に退勤時間を付ける」にチェックを入れると、予定の名前に時間が付きます。2つは別々に選べます。

1
1(10:00)
  • 出勤は、泊・日勤の番号のあとに出勤時間が付きます(例: 1(10:00)。日勤も出勤時間だけ)
  • 非番は、「〜」のあとに退勤時間が付きます(例: 〜(9:00))。「〜」「非番」などを手入力した日も、メモに退勤時間を書けば付きます
  • メモは今までどおりです。時間はメモの1行目の先頭から読むので、メモを書き換えた日は書き換えた時間が付きます(「10:00 早出」のように後ろに言葉があっても付きます。時間で始まらないメモの日は、番号や「〜」だけです)。休日(公休・年休など)には付きません
  • 「2段」と一緒に使うこともできます(上の予定の名前に時間が付きます)
  • 「勤務を時間つきの予定で登録する」がオンのあいだは使われません
  • 次に登録する分から変わります。変えたい月は、登録し直します。チェックを外せば元の名前に戻ります(これも登録し直した月から)
勤務を時間つきの予定で登録する

設定の「勤務を時間つきの予定で登録する」にチェックを入れると、出勤の予定が、終日ではなく時間つきになります。アプリのカレンダーでは、帯は番号のままで、帯をタップすると、出勤〜退勤の時間が出ます(泊は、出勤から翌日の退勤までの1件になります)。アプリのカレンダーだけで使う人には、使いやすい設定です。

Googleカレンダーにも登録する人は、Googleカレンダーにも時間つきで入ります。ただし、Googleカレンダーのアプリで見る人にはおすすめしません(月の表示では、泊が始まりの日にしか出ず、翌日の非番につながって見えません)。Googleカレンダーで見る人は、チェックを入れずに、「2段」「名前に時間を付ける」を使ってください。

  • 泊は、出勤時間から翌日の退勤時間までの1件になります(名前は番号、メモは泊地)。翌日の非番の「〜」は入りません。非番の日のメモに時間のあとの言葉(例: 9:00 天王寺)があれば、泊のメモの後ろに入ります。月末の泊は、翌月1日の退勤時間までです
  • 日勤は、出勤時間から退勤時間までです(メモは今までどおり「出勤〜退勤」)
  • 休日(公休・年休など)は、今までどおり終日です
  • 時間はメモから読むので、メモを書き換えた日は書き換えた時間になります(泊の日のメモは出勤時間、非番の日のメモは退勤時間)。時間で始まらないメモにした日は、今までどおり終日です(泊のときは、泊と「〜」の2件とも終日)
  • 一覧にない番号を手入力した泊は、泊の日のメモに「10:00 大阪」のように出勤時間(そのあとに泊地。空白はなくてもよい。泊地はなくてもよい)、翌日を「〜」にしてメモに「9:00」のように退勤時間を書くと、1件になります。月末の手入力の泊は、終日のままです。手入力の日勤は、メモに「10:00〜18:00」のように書きます
  • オンのあいだは、「2段」「名前に時間を付ける」は使われません(チェックは押せなくなります)
  • 次に登録する分から変わります。変えたい月は、登録し直します。切り替えた月の前の月の月末が泊なら、前の月も登録し直すと、つなぎ目がそろいます(登録し直すまでは、前の月の泊は終日のままで、1日には「〜」が入ります)
勤務表の写真から取り込む(写真取込)

勤務入力の画面の「写真取込」を押すと、Claude(AI)のページが開きます。勤務指定表の写真から自分の行を読み取って、勤務入力に入れられます。やり方は Android と iPhone・iPad で違います(Claude のページの上の「Android・PC」「iPhone・iPad」で切り替えます。最初は使っている端末に合わせて選ばれています)。

共通

  • Claude のアプリとアカウントが必要です。持っていない人は、先に Claude のアプリを入れて新規登録してください。持っている人は、ログインしておきます(無料プランでも使えます)
  • 読み取りには、自分の Claude の使用量を使います(shiftflow や、他の人の分は使いません)。何回も読み取ると上限に達して、最大5時間ほど使えなくなります。その間は Claude のチャットなども使えません
  • 取り込んだあとは、まだカレンダーには入っていません。取り込んだ日は青く、変・臨時など一覧にない番号で時間の無い日は黄色になります。勤務表では「1」でも、一覧が「特1」のように頭に文字が付いた番号(同じ数字のものが1つだけ)なら、一覧の番号として入ります。分かればメモに時間を入れ、確かめて「登録」か「保存」を押してください(分からなければ「保存」しておき、後で入れられます)
  • 写真は、読み取るときに自分の Claude に送るだけで、shiftflow には送りません。今月より前の月は取り込めません

Android・PC(Claude のページの「読み取る」で読み取ります)

  1. 名前(勤務表に書かれているとおり)・月・写真を入れて「読み取る」を押します。30秒〜1分ほどかかります。最初だけ「Claude に写真を送ってよいか」の確認が出るので「許可」を選びます
  2. 上の写真と下の表を見比べて、違う番号を直します
  3. 「勤務入力に反映」を押すと、この画面が開いて、確認のあとにその月の入力が置き換わります
  • 「読み取る」がエラーになる・押せないときは、まずブラウザで開き直します。Chrome で claude.ai を開いてログインし(アプリでログインしていても、ブラウザは別です)、同じ Chrome で 写真取込のページ を開いて「読み取る」を押します。それでもだめなときは、Claude のページの「エラーが出る・読み取れないとき」の「指示文をコピー」を使って、下の iPhone・iPad と同じようにチャットで読み取ります
  • 「勤務入力に反映」で開けないときは、Claude のページの「コピー」を押してから、この画面の「貼り付けで取込」に貼り付けます
  • 「勤務入力に反映」で開いた画面で shiftflow のログインを聞かれたら、一度ログインしてください。次からは聞かれません(その画面にログインが保存されます)
  • shiftflow をホーム画面に追加して使っている人は、写真取込のときはブラウザ(Chrome)で shiftflow を開くと、ログインし直しが少なくて済みます

iPhone・iPad(Claude のページの「読み取る」は使えません。Claude のアプリでも Safari でも同じです。代わりに Claude のアプリのチャットで読み取ります)

  1. Claude のページの上で「iPhone・iPad」を選び、名前・月を入れて「指示文をコピー」を押します
  2. ページを閉じて(左上の ✕)、Claude のアプリで新しいチャットを開きます
  3. 入力欄の左の「＋」を押し、「カメラ」で勤務表を撮るか「写真」から選んで付けます。そのあと、入力欄に指示文を貼り付けて送ります
  4. 返ってきた答えの「コード」と書かれた枠の右上の、四角が2つ重なったマークを押してコピーします(自分が送った指示文の枠ではなく、Claude の答えの枠のほう)
  5. この画面に戻り、「貼り付けで取込」を押して貼り付け、「取り込む」を押します。確認に、読み取った行の名前が出るので、自分の名前か確かめます
交番から休みを入れる

交番の休み(特休・公休)を、月ごとに自動で入れられます。行路は入りません(行路は今までどおり自分で入れるか、写真取込で)。

はじめに1回だけ(⚙)

  1. 勤務入力の左上の「⚙」を押します
  2. 「一周の日数」(何日で同じ並びに戻るか。はじめは30日)と「入力する月」を選びます。その月の1日から、一周分のカレンダーが出ます。本番の月で入力してください
  3. 交番の自分の行を見て、その月の休みの日をタップします。タップするたびに「なし → 特休 → 公休 → なし」と切り替わります
  4. 予備の月は「予備の月も休みを入れる / 予備の月は何もしない」を選びます。何もしないときは、何もしない月を押して選びます(例 2・5・8・11月)
  5. 「保存」を押します

月ごとに: 入れたい月を出して「交番」を押し、OK を押します。そのあと「保存」か「登録」を押します。

  • 休みの日だけ上書きします。ほかの日(自分で入れた行路など)はそのままです
  • 前の日が泊の日(非番)には入れません
  • 休みは交番から入れてください。実際の勤務指定表(年休などが入っている)から入れると、次の月からずれます
  • ダイヤ改正などで交番の並びが変わったら、「⚙」で入れ直してください
リセット(カレンダーから消す)

「リセット」(4)を押して月を選び、「削除」を押すと、その月にこのアプリで登録した予定を、カレンダーから消し、画面の入力内容も空にします。手で入れた予定は消えません。

3. shiftflowカレンダー(アプリ内のカレンダー)

上のメニューの「カレンダー」で開きます。Googleカレンダーを使わなくても、勤務入力で保存した勤務を、月の画面で見られます(点呼の確認などに)。ホーム画面に別のアプリとして追加すると、アプリのように開けます(最初に1回、社員番号とPINでログインします)。

  • 勤務の予定は、勤務入力で直します。名前や時間の付き方は、勤務入力の設定どおりです。
  • 自分の予定は、下の「＋」で追加します。日を長押し(0.5秒ほど)しても、その日の予定の追加が開きます(短いタップは、その日の予定の一覧です)。時刻は分単位で、日をまたぐ予定は終了日を次の日にします。繰り返し(毎日・毎週・毎月・毎年)と、「この回だけ」の変更・削除もできます。
  • 上のラベルのボタンを押すと、そのラベルの予定が消えます。もう一度押すと戻ります。勤務・休日は、別々のボタンです。カレンダーの設定の「このカレンダーに出すもの」で、勤務・休日を出すか、非番(「〜」とその時間)を別のボタンにするかを決めます。Googleカレンダーに登録している人は、休日用・非番の時間用のカレンダーの有無から、最初のチェックが決まります。Googleを使わない人は、最初は勤務と休日にチェックがあり、非番を別にしたいときは、チェックを入れます。ラベルの色と並び順は、カレンダーの設定で決めます。
  • 写真は、1つの予定に3枚までです。小さくして保存し、予定が終わって1か月で消えます。「画像」(★の隣)は、日程表などを1人10枚まで置けます(自動では消えません)。
  • スタンプ・TODO・重要メモも使えます。
  • 月のカレンダーを画像にする: 下のメニューの「設定」の中、「ラベル」の下にあります。月を選んで「画像を作る」を押すと、その月のカレンダーが1枚の画像(横1080px)になります。いま上のラベルのボタンで表示している予定(隠したラベルの予定は入りません)と、置いたスタンプが入ります。「共有する」でLINEなどに送れます。共有できない端末では、画像を保存します。画像は端末の中で作り、サーバーには送りません。選べる月は、過去1年から来年の12月までです。
  • 選んだ日に〇をつけて画像にする: 「日を選ぶ」を押すと、設定が閉じてカレンダーが見えます。予定を見ながら日をタップすると赤い〇がつき、もう一度タップで外せます。下に出る「画像を作る」を押すと、設定に戻って画像が出ます。画像には予定やスタンプは入らず、選んだ日の〇だけが入ります。月をまたいで選ぶと、月ごとに1枚ずつ作ります。日を選んでいる途中で、予定の追加・設定・スタンプなどのメニューを押すと、選ぶのをやめます(選んだ日は残ります)。「選んだ日を全部外す」で、選びを空にできます。
  • 見返せるのは過去1年までです。それより前の予定とスタンプは、自動で消えます。
  • カレンダーは1つのアカウントで1人分です。家族に見せたいときは、このアプリのURLを教えて、その人が自分のアカウントでログインして使うか、勤務をGoogleカレンダーに登録して共有します。
  • これから使い始める人は、最初は「Googleカレンダーにも登録する」のチェックが外れています。接続テストなしで、保存だけで使えます。Googleカレンダーにも登録したい人は、設定でチェックを入れて、カレンダーIDを入れ、接続テストをします(すでにGoogleカレンダーに登録して使っている人は、チェックが入ったままです)。

5. Googleカレンダーとの連携(他のカレンダーに同期したい人)

Googleカレンダーとの連携は、勤務を、アプリ以外のカレンダーにも同期したいときに必要です。連携すると、勤務入力の「登録」で、Googleカレンダーに予定が入ります。それを、スマホの標準カレンダーや TimeTree などの他のカレンダーアプリで見たり、家族に共有したりできます(同期のしかたは、5-C を見てください)。

アプリのカレンダー(上のメニューの「カレンダー」)だけで使う人は、連携はいりません。この章は読まなくて大丈夫です(あとから、設定の「Googleカレンダーにも登録する」にチェックを入れて、始められます)。

設定は、スマホで設定するかパソコンで設定するかを選びます。どちらも、最初の1回だけです。

5-A. スマホで設定する(パソコンはいりません)

パソコンがなくても、スマホだけで最後まで設定できます。流れは、① チェックを入れる → ② 簡単設定でカレンダーを作る → ③ 共有する → ④ 区所とIDを確かめて接続テストです(10〜15分ほど。最初の1回だけ)。

必要なもの: Googleカレンダーのアプリ(Android・iPhone 共通。入れていない人は、先に入れます。共有に使います)。勤務表の写真から取り込む(写真取込)ときだけ、Claude(AI)のアプリとアカウント(無料可。詳しく)。

① 「Googleカレンダーにも登録する」にチェックを入れる

アプリの「設定」画面で、「Googleカレンダーにも登録する」にチェックを入れます。下に、Googleカレンダーの設定(簡単設定・登録用アドレス・カレンダーID)が出ます。

② 簡単設定で、勤務用のカレンダーを作る

このアプリ専用のカレンダーを、新しく作ります。自分のメインのカレンダーは使えません。手で入れている予定とも分けられるので、安心です。

  1. アプリの「設定」画面を開く
  2. 「1. 区所を選ぶ」の下の「簡単設定」で、勤務用のカレンダーの名前を決める(そのままの「勤務」でも構いません)

許可は、アプリが作ったカレンダーだけです(メインのカレンダーや予定は、見られません)。許可はこの画面の中だけで使い、保存しません。Googleの画面には、アプリの名前の代わりに「fast4213-max.github.io」と出ます(下の図)。アカウントを選び、「メイン以外の Google カレンダーの作成…」と出たら、「次へ」を押します。

作り直した・足したあとは、すでに登録した月を、勤務入力でもう一度「登録」します(新しいカレンダーには、まだ予定が入っていません)。入れ替えた前のカレンダーの予定は残るので、いらなければ前のカレンダーを削除します(カレンダーごと消せるのは、ブラウザの「PC表示」のGoogleカレンダーだけで、スマホのアプリからは消せません。入れ替えたあとに出る「前のカレンダーの設定を開く」のリンクから、一番下の「カレンダーを削除」へ進めます)。

Googleカレンダーのアプリで共有する(Android・iPhone 共通。スマホだけでできます)

④ 区所を選んで、接続テスト

  1. アプリの「設定」画面を開き、「Googleカレンダーにも登録する」にチェックを入れる(下にGoogleカレンダーの設定が出ます)
  2. 1 「区所」を選ぶ(番号の一覧は区所ごとに違います。下の「保存して接続テスト」を押すまでは保存されません)

  4. 3 「勤務用カレンダーID」に、コピーしたID(「カレンダーIDを調べる」)を貼り付ける(簡単設定で作った人は、もう入っています)

休みも勤務用のカレンダーに入れたい人は、簡単設定で「勤務用のカレンダーに、一緒に入れる」を選びます(手で入れるときは、「休日用カレンダーID」に、勤務用と同じIDを貼り付けます。休日用のカレンダーは作らなくて大丈夫です)。
休日用を空にすると、「休日」の番号(公休・年休など)は、カレンダーに登録されません。

「接続できました」と出れば、準備は完了です。

5-B. パソコンで設定する

パソコンのブラウザで calendar.google.com を開いて設定する人向けです。流れは、① カレンダーを作る → ② 共有する → ③ カレンダーIDを調べる → ④ アプリの設定に貼って接続テストです。簡単設定(アプリの設定画面の「Googleでカレンダーを作る」)は、パソコンのブラウザでも同じように使えます(上の 5-A の②)。簡単設定で作った人は、①と③はいりません(IDは自動で入ります)。②の共有から進めます。

画面の写真は、スマホの画面です。パソコンでは、同じ名前の項目を探してください(Googleの画面は変わることがあります)。

① カレンダーを手で作る(簡単設定を使わないとき)

  1. ブラウザ(スマホは「PC表示」にして)で https://calendar.google.com を開く
  2. 右上の歯車(1)を押し、「設定」(2)を選ぶ
  3. 左のメニューの「カレンダーを追加」を開き、「新しいカレンダーを作成」(1)を選ぶ(下の図)
  4. 名前(例: 勤務)を入れて「カレンダーを作成」

休日用・非番の時間用のカレンダーも分けたい人は、同じ方法で作ります(休日用・非番の時間用は、なくても構いません)。左の「他のカレンダー」の横の「＋」からも、同じ「新しいカレンダーを作成」に進めます。作ったあとのIDは、下の「カレンダーIDを調べる」で調べます。

② 共有する

共有する相手は、アプリの登録用アドレスです(5-A の③の枠、または設定画面の「登録用アドレス」の「コピー」で、コピーできます)。作ったカレンダーを、1つずつ全部共有します(勤務用・休日用・非番の時間用)。

手順A: 共有の画面を開く

  1. ブラウザ(PC表示)で calendar.google.com を開き、右上の歯車 →「設定」の画面で、左のメニューの「マイカレンダーの設定」の中の「勤務」(図の 1)を押す
  2. 右の「共有する相手」の欄が共有の画面です(カレンダーの左の「︙」→「設定と共有」からも開けます)

手順B: アドレスを追加して、権限を選ぶ

  1. 「＋ ユーザーやグループを追加」(図の 2)を押す
  2. 出てきた画面の上の欄に、コピーした登録用アドレスを貼り付ける(右の図の 1)
  3. 権限の一覧から、上から4番目の「すべての予定の詳細の変更や表示ができます」(右の図の 2)を選ぶ
  4. 「送信」を押す(一覧を開いていると隠れています。選ぶと閉じて、下に出ます)
  5. 共有できると、「共有する相手」の欄に登録用アドレスが増え(図の 3)、権限が「すべての予定の詳細の変更や表示が…」になっています
権限はここだけ間違えないでください。
・上の2つ(「予定の表示…」「予定の詳細の表示」)では、アプリが書き込めません。
・3番目の「変更可能(限定公開の予定を…)」ではなく、4番目を選びます。
・一番下の「予定の変更および共有の管理」は、強すぎるので選ばなくて大丈夫です。
・画面によっては「予定の変更権限」などの名前のこともあります。そのときは、予定を変更できるもので、共有の管理が付いていないものを選びます。

③ カレンダーIDを調べる

簡単設定で作った人は、IDが自動で入って保存されているので、この手順はいりません。④に進みます。

上の手順A(ブラウザ)で開いた「勤務」の設定の画面を、下にスクロールします(Googleカレンダーのアプリの設定画面には、IDは出ません)。

  1. 「カレンダーの統合」という見出しを探す
  2. その中の「カレンダー ID」(1)の文字列を、全部コピーする
合っているID使えないもの
英数字の長い文字列の後ろに @group.calendar.google.com が付いている 自分のメールアドレスのID(メインのカレンダー) / カレンダーの名前 / 共有用のURL

前後に空白が入らないように、コピーして貼り付けます。休日用・非番の時間用を作った人は、そのカレンダーのIDも同じように調べます。

④ アプリの設定に貼って、接続テスト

アプリの「設定」画面で、「Googleカレンダーにも登録する」にチェックを入れ、「区所」を選び、「勤務用カレンダーID」(休日用・非番の時間用を作った人は、そのIDも)を貼り付けて、「保存して接続テスト」を押します。詳しくは、5-A の④です。「接続できました」と出れば、準備は完了です。

5-C. スマホのカレンダーアプリで見る設定(Android / iPhone)

登録した勤務の予定は、スマホのカレンダーアプリで見られます。見るために必要な設定は、使うスマホで違います。

Androidの人

1このアプリ(Webアプリ)で勤務を入力して「登録」
2Googleカレンダーに予定が入る
3お好きなカレンダーアプリで見る
Googleカレンダーの同期をオンにしてあれば、Googleカレンダーとつながるカレンダーアプリで、予定が出ます

「Googleカレンダー」アプリで見る人は、勤務用・休日用・非番の時間用のカレンダーが「表示(同期)」になっていれば、そのまま見られます(「Googleカレンダー」アプリの左上のメニューで、勤務用[作った人は休日用・非番の時間用も]のカレンダーにチェックを入れます)。他のカレンダーアプリを使う人は、そのアプリにGoogleアカウントをつなぎ、Googleカレンダーの同期をオンにします。

iPhone・iPadの人

1このアプリ(Webアプリ)で勤務を入力して「登録」
2Googleカレンダーに予定が入る
3iPhoneの標準の「カレンダー」アプリに、Googleカレンダーを同期する
下の設定をします(最初の1回だけ)
4お好きなカレンダーアプリで見る
標準カレンダーの同期をオンにしてあれば、標準カレンダーとつながるカレンダーアプリでも、予定が出ます
iPhone・iPadに最初から入っている「カレンダー」アプリ(赤いアイコン)や、それとつながるカレンダーアプリで勤務を見たい人は、下の設定が必要です。「Googleカレンダー」アプリで見る人は、いりません。

上の3番の設定のしかた(標準カレンダーに同期する)

iPhoneにGoogleアカウントを追加します。最初の1回だけです。

  1. iPhoneの「設定」アプリを開く
  2. 「カレンダー」を押す(iOS 18以降は、「アプリ」の中にあります)
  3. 「アカウント」→「アカウントを追加」の順に押し、「Google」を選ぶ
  4. 勤務用のカレンダーを作ったGoogleアカウントのメールアドレスとパスワードを入れてログインする
  5. 同期する項目の中の「カレンダー」のスイッチをオンにして、「保存」を押す

これで、iPhoneの標準の「カレンダー」アプリに、アプリで登録した勤務の予定が出ます。標準カレンダーとつながる他のカレンダーアプリ(お好きなもの)でも、標準カレンダーの同期がオンなら、同じ予定が見られます。

出てこないとき
・反映まで、数分かかることがあります。「カレンダー」アプリを開き、下の「カレンダー」を押して、勤務用・休日用・非番の時間用のカレンダーにチェックが入っているか確認します。
・それでも出ないときは、スマホのブラウザで calendar.google.com/calendar/syncselect を開き、勤務用・休日用・非番の時間用のカレンダーにチェックを入れて「保存」を押します。
・設定は、カレンダーを作ったのと同じGoogleアカウントで行います(別のアカウントを追加しても、勤務の予定は出ません)。

どちらのスマホでも、予定を登録する手順(「2. 勤務を入力する」)は変わりません。登録はこのアプリで行い、スマホのカレンダーは見るだけに使います(スマホのカレンダーで予定を消したり直したりもできますが、このアプリで登録し直すと元に戻ります)。

接続テストが失敗したとき

出た文確認すること
「○○カレンダーに書き込めません」権限が「すべての予定の詳細の変更や表示ができます」か。共有した相手のアドレスが、登録用アドレスと同じか(コピーが確実)。IDの貼り間違いや空白がないか。勤務用と(使う人は)休日用・非番の時間用の、全部で共有したか

「1. で区所を選んでください」「設定画面で区所を選んでください」設定画面の「1. 区所を選ぶ」で区所を選んで、もう一度「保存して接続テスト」を押します

共有した直後は、反映まで少し時間がかかることがあります。数分おいて、もう一度試してください。

6. こまったとき
ログインできない
社員番号(7桁)とPIN(4桁)が合っているか確認します。まだ登録していない人は、最初の画面の「新規登録」から登録します(共通パスワードは管理者に聞きます)。「続けて間違えたため…」と出たときは、出ている時間だけ待ってからやり直します(長いときや、PINを忘れたときは、管理者にPINの再設定を頼みます)。スマホの人は、「4. ホーム画面に追加する」の「iPhone・Androidでログインできないとき」も確認します。
それでも解決しない・他に困ったことがある
お問い合わせから管理者に送れます(ログイン前でも使えます。ログイン後は上のメニューの「お問い合わせ」)。返事は、ログイン前に送ったときは画面(受付番号と確認コード)、ログイン後は「これまでのお問い合わせ」で見られます。メールでも受け取れます。メールのときは、shiftflow.kinmu@gmail.com から届くので、迷惑メールフォルダも見てください。画像は3枚まで付けられます(iPhoneは「写真ライブラリ」から選びます)。PINは書かないでください。
お知らせはどこで見られますか?
ログイン画面の入力欄の上と、ログイン後の上のメニューの「お知らせ」で見られます。新しいお知らせがあると、メニューに赤い点が付きます。
PINを忘れた
管理者に再設定を頼みます。仮のPINで入って、設定画面の「PINを変える」から好きなPINに変えます。再設定・変更のあとは、スマホに保存した古いPINが自動で入ることがあるので、手で入力します(他の端末のログインは消えます)。
登録するのに共通パスワードが必要と言われた
管理者が決めたパスワードです。管理者に聞いてください。登録のときにしか使いません。
番号の一覧に、自分の番号がない
設定画面で、自分の区所が選ばれているか確認します。一覧にない番号は「手入力」で入れられます。一覧に足したいときは、管理者に頼みます。
手で入れた予定が消えませんか?
消えません。勤務入力の保存・リセットで変わるのは、勤務の予定だけです。アプリのカレンダーで自分で入れた予定は変わりません。Googleカレンダーに登録している人も、このアプリは自分が作った予定に目印を付けていて、登録し直しやリセットのときは、目印のある予定だけを消して作り直します。
スマホのカレンダーに出ない(Google連携の人)
先に「5-C. スマホのカレンダーアプリで見る設定」を確認します。iPhone・iPadの標準の「カレンダー」アプリで見る人は、Googleアカウントの追加が必要です。済んでいるのに出ないときは、スマホのカレンダーアプリで、勤務用・休日用・非番の時間用のカレンダーが「表示(同期)」になっているか確認します。反映まで少し時間がかかることがあります。
後から休日用・非番の時間用のカレンダーを足したい(Google連携の人)
設定画面の「簡単設定」で、「勤務用のカレンダー」を「そのまま使う」にして、作りたいものだけ選んで押します(休日は「休日用のカレンダーを別に作る」、非番の時間は「非番の時間用のカレンダーも作る」にチェック)。作ったカレンダーを共有して、「保存して接続テスト」を押します。
カレンダーを変えたい(Google連携の人)
設定画面の「簡単設定」で、「勤務用のカレンダー」を「新しく作って入れ替える」にして作ります(休日用・非番の時間用だけ足すときは「そのまま使う」)。作ったカレンダーを共有して、「保存して接続テスト」を押します。手で作ったカレンダーに変えるときは、共有してから、設定画面でIDを入れ直して「保存して接続テスト」を押します。変えたあとは、登録済みの月を、勤務入力でもう一度「登録」します(新しいカレンダーには、まだ予定が入っていません)。前のカレンダーの予定を消したいときは、カレンダーを変える前に「リセット」で消します(リセットは、その月の画面の入力内容も空にするので、入力を残したいときは使えません。そのときは、前のカレンダーを、ブラウザの「PC表示」のGoogleカレンダー(スマホのアプリからは消せません)の「設定と共有」から削除します。手で入れた予定も一緒に消えます)。非番の時間用カレンダーを足した・変えたときも同じです(使うのをやめるときは、上の「非番を2段で出す」を見てください)。
使うのをやめたい / 共有を止めたい
Googleカレンダーと連携していない人は、共有を止める作業はいりません。アプリのデータを消したいときは、お問い合わせから頼みます(管理者が削除すると、カレンダーの予定・写真・画像も一緒に消えます)。
Googleカレンダーと連携している人は、Googleカレンダーのアプリなら「≡」→「設定」→カレンダー名→「共有する相手」で、登録用アドレスの横の削除(×)を押します(ブラウザの「PC表示」なら「設定と共有」→「共有する相手」)。これだけで、アプリはあなたのカレンダーに書き込めなくなります。登録済みの予定は残るので、不要なら先に「リセット」で消します。
個人のデータはどうなりますか?
社員番号・名前・区所・入力した勤務の番号とメモ・shiftflowカレンダーに入れた予定・写真・画像など(Googleカレンダーにも登録する人は、カレンダーIDも)は、このアプリのデータベースと保管場所に保存されます。お問い合わせの内容とメールアドレスは、最後のやり取りから90日で自動で消えます(付けた画像はデータベースには保存せず、管理者の Discord と Gmail に届き、90日で消えます)。PINは暗号化した形で保存され、管理者にも分かりません(管理者がPINを再設定すると、その人として入れます。本人はログアウトされます)。管理者には、社員番号・名前・区所・最終ログイン日時・最後に登録した日・記録の日数、写真・画像の使用量が多い人の量が見えます(勤務の中身、カレンダーの予定・写真・画像の中身、カレンダーIDは見えません)。最初の設定では、Googleカレンダーには何も書き込みません。Googleカレンダーにも登録する人も、アプリが書き込めるのは、あなたが共有したカレンダーだけです。くわしくは利用上の注意とプライバシーを見てください。
