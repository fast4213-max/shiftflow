CSV を取り込む

1行目は 番号,種別,平日出勤,平日退勤,休日出勤,休日退勤,泊,平休出勤,平休退勤,休平出勤,休平退勤(「泊」と、平休・休平の4列は無くてもよい)。種別は 泊 / 日勤 / 休日。平休は「平日に泊→翌日が休日」、休平は「休日に泊→翌日が平日」のときの泊の出勤・退勤(空なら今までどおり平日・休日の列を使う)。

取り込む内容です。時刻はそろえた形で表示しています。赤い行は直してから取り込んでください。

新規登録の共通パスワード

利用者が新規登録するときに入力するパスワードです。変えても、すでに登録した人には影響しません。

カレンダーの登録用アドレス

利用者がカレンダーを共有する相手です(サービスアカウント)。

データベースの停止対策(cron-job.org)

無料プランは1週間ほど使われないと止まります。cron-job.org で、次の内容を6時間ごとに実行するよう登録します。

もう1つのヘッダー: Content-Type: application/json、本文: {}

Supabase アクセストークンの期限

GitHub の自動デプロイ(Secrets の SUPABASE_ACCESS_TOKEN)に使っています。切れると、データベースと関数の更新だけが止まります(いま動いているアプリは止まりません)。新しく作ったら、GitHub の Secrets を上書きし、web/js/config.js の TOKEN_EXPIRES の日付を書き換えます。

管理用パスワード

この画面に入るパスワードは、Supabase のダッシュボード「Edge Functions」→「Secrets」の ADMIN_PASSWORD です(12文字以上)。変えるときはそこを書き換えてください。

仮のPINを発行しました

この画面を閉じると二度と表示されません。本人に伝えて、ログイン後に設定画面の「PINを変える」で好きなPINに変えてもらってください。
