1. 利用上の注意(免責)

  • このアプリは、勤務の入力とGoogleカレンダーへの登録を楽にするための、個人が運営するツールです。勤め先の公式のものではありません。
  • 勤務の内容は、必ず会社の公式の勤務表で確認してください。マスタの誤り、入力の間違い、登録のやり直しなどで、カレンダーの予定が実際の勤務と違うことがあります。
  • 動作や、予定が正しく登録されることは保証しません。アプリの利用や不具合、Googleカレンダーの予定の変化・消失などで生じた損害について、運営者は責任を負えません。
  • アプリは、予告なく内容を変えたり、止めたり、終了したりすることがあります。
  • アプリが書き込むのは、あなたが共有したカレンダーだけです。共有はいつでも止められます(使い方の「使うのをやめたい / 共有を止めたい」を見てください)。
  • PINは他の人に教えないでください。PINの管理は、ご自身の責任でお願いします。

2. 個人情報の扱い

預かる情報
社員番号・名前・区所・カレンダーID・入力した勤務の番号とメモ・ログインの記録(最終ログイン日時と失敗の回数)。PINは暗号化した形で保存します。お問い合わせをしたときは、その内容と、入力したメールアドレス・付けた画像も預かります。
使う目的
ログインと本人の確認、勤務の入力とGoogleカレンダーへの登録、お問い合わせへの返事、不正な利用の防止にだけ使います。広告やその他の目的には使いません。
管理者に見えるもの
社員番号・名前・区所・最終ログイン日時・最後に登録した日・記録の日数。勤務の中身(番号・メモ)とカレンダーIDは見えません。お問い合わせの内容は、返事のために見えます。
保存する期間
勤務の記録は、前月1日より前のものを毎日消します(Googleカレンダーの予定は消しません)。ログインの失敗の記録は、30日以上更新がないと消えます。お問い合わせの内容とメールアドレスは、最後のやり取りから90日で消えます。付けた画像は、データベースには保存せず、管理者の Discord と Gmail に届き、90日で消えます。
外部のサービス
データの保管と処理に Supabase、カレンダーへの登録に Google、画面の公開に GitHub Pages を使っています。お問い合わせの受付と返事には Gmail と Discord を使います。これらの提供元の取り扱いは、それぞれの規約に従います。法令に基づく場合を除いて、上記のほかに第三者へ渡すことはありません。
Google アカウントのデータの扱い
設定画面の「かんたん設定」でGoogleの許可をすると、あなたのGoogleカレンダーに、このアプリ用のカレンダーを作るためだけに使います(許可の範囲は、アプリが作ったカレンダーだけです。メインのカレンダーや予定は、見ることも変えることもできません)。許可は、その画面の中だけで使い、このアプリのデータベースにも、他のどこにも保存しません。カレンダーを作り終えたら、すぐに取り消します(途中で画面を閉じたときは、約1時間で自動的に切れます)。Googleから受け取った情報を、広告や、上記以外の目的に使うことも、第三者へ渡すこともありません。この使い方は、Google API サービスのユーザーデータに関するポリシー(限定的な使用の要件を含む)に従います。
確認・削除したいとき
お問い合わせから連絡してください。本人かどうかを確かめたうえで対応します。
