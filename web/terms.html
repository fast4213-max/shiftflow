このアプリを使うと、このページの内容に同意したものとみなします。

1. 利用上の注意(免責)

  • このアプリは、勤務の入力と、アプリの中のカレンダー(shiftflowカレンダー)での確認を楽にするための、個人が運営するツールです。勤め先の公式のものではありません。Googleカレンダーへの登録は、他のカレンダーアプリや家族に同期したい人だけが、設定で使います。
  • 勤務の内容は、必ず会社の公式の勤務表で確認してください。マスタの誤り、入力の間違い、保存・登録のやり直しなどで、カレンダーの予定が実際の勤務と違うことがあります。
  • 動作や、予定が正しく表示・登録されることは保証しません。アプリの利用や不具合、カレンダーの予定の変化・消失(Googleカレンダーに登録した予定を含む)などで生じた損害について、運営者は責任を負えません。
  • アプリは、予告なく内容を変えたり、止めたり、終了したりすることがあります。
  • 最初の設定では、Googleカレンダーには何も書き込みません。「Googleカレンダーにも登録する」を使う人も、アプリが書き込むのは、あなたが共有したカレンダーだけです。共有はいつでも止められます(使い方の「使うのをやめたい / 共有を止めたい」を見てください)。
  • PINは他の人に教えないでください。PINの管理は、ご自身の責任でお願いします。
  • カレンダーの共有は、あなたが「共有する」を押した相手(または、あなたのお誘いを受けた相手)にだけ、あなたが選んだ範囲の勤務を見せます。共有はいつでもやめられます。

2. 個人情報の扱い

預かる情報
社員番号・名前・区所・入力した勤務の番号とメモ・ログインの記録(最終ログイン日時と失敗の回数)に加えて、shiftflowカレンダーに入れた内容(自分で作った予定・メモ・ラベル・スタンプ・TODOメモ・重要メモ・予定のテンプレート、付けた写真と「画像」に置いた画像)。Googleカレンダーにも登録する人は、カレンダーIDも預かります。PINは暗号化した形で保存します。お問い合わせをしたときは、その内容と、入力したメールアドレス・付けた画像も預かります。
カレンダーの共有
共有した相手には、あなたの名前と、あなたが選んだ範囲の勤務(「勤務だけ」なら勤務の番号と時間、「勤務と休日」なら休日も)だけが見えます。勤務のメモは、先頭の時間だけが見えます(手で書いた言葉は見えません)。自分で作った予定・写真・画像・TODO・重要メモ・スタンプは見えません。お誘いを送った相手には、相手が「共有する」を押すまで、あなたの名前だけが見えます(送った側には、相手の名前は見えません)。共有の記録は、やめたとき・退会したときに消えます。お誘いは30日で消えます。
「夫婦」の共有では、招待した人のカレンダーを2人で使うため、その中の予定・メモ・ラベル・スタンプ・TODOメモ・重要メモ・予定のテンプレート・写真・画像が、2人に見えて、2人とも直せます(「自分だけ」にしたラベルと、その予定は除きます)。やめたとき・退会したときは、招待された人が作ったものを、招待された人のカレンダーへ移します。
使う目的
ログインと本人の確認、勤務の入力とshiftflowカレンダーでの表示、Googleカレンダーへの登録(その設定の人だけ)、お問い合わせへの返事、不正な利用の防止にだけ使います。広告やその他の目的には使いません。
管理者に見えるもの
社員番号・名前・区所・最終ログイン日時・最後に登録した日・記録の日数、写真・画像の使用量(ファイルの大きさの合計)が多い人の社員番号・名前と量(無料の容量の管理のため)。勤務の中身(番号・メモ)、カレンダーに入れた予定・メモ・写真・画像の中身、カレンダーIDは見えません。お問い合わせの内容は、返事のために見えます。
保存する期間
勤務の記録は、13か月前の月の1日より前のものを毎日消します(Googleカレンダーに登録した予定は消しません)。shiftflowカレンダーの予定とスタンプは、12か月前の月の1日より前のものを毎日消します(終わりの無い繰り返しの予定は消えません)。予定に付けた写真は、予定が終わって1か月で消えます。「画像」に置いた画像は、自分で消すまで残ります(1人10枚まで。夫婦の共有で一緒に使うカレンダーは20枚まで)。ログインの失敗の記録は、30日以上更新がないと消えます。お問い合わせの内容とメールアドレスは、最後のやり取りから90日で消えます。付けた画像は、データベースには保存せず、管理者の Discord と Gmail に届き、90日で消えます。
外部のサービス
データの保管と処理に Supabase(写真・画像のファイルの保管を含む)、Googleカレンダーへの登録(その設定の人だけ)に Google、画面の公開に GitHub Pages を使っています。お問い合わせの受付と返事には Gmail と Discord を使います。これらの提供元の取り扱いは、それぞれの規約に従います。法令に基づく場合を除いて、上記の他に第三者へ渡すことはありません。
Google アカウントのデータの扱い
設定画面の「簡単設定」でGoogleの許可をしたときは、その許可を、あなたのGoogleカレンダーにこのアプリ用のカレンダーを作るためだけに使います(許可の範囲は、アプリが作ったカレンダーだけです。メインのカレンダーや予定は、見ることも変えることもできません)。許可は、その画面の中だけで使い、このアプリのデータベースにも、他のどこにも保存しません。カレンダーを作り終えたら、すぐに取り消します(途中で画面を閉じたときは、約1時間で自動的に切れます)。Googleから受け取った情報を、広告や、上記以外の目的に使うことも、第三者へ渡すこともありません。この使い方は、Google API サービスのユーザーデータに関するポリシー(限定的な使用の要件を含む)に従います。
確認・削除したいとき
お問い合わせから連絡してください。本人かどうかを確かめたうえで対応します。
