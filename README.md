# shiftflow

スマホから勤務を手入力し、Googleカレンダー(勤務用・休日用)に終日予定として登録する、
スプレッドシート + Google Apps Script(GAS)だけで動く個人用Webアプリです。
ライフベアへはGoogleカレンダー側の連携で反映します。

## ファイル

```
gas/Code.gs          サーバー側(シート読み書き・祝日判定・カレンダー登録)
gas/index.html       入力画面(月ごとの日付一覧)
gas/appsscript.json  マニフェスト
```

## 登録される予定(すべて終日)

| 種別 | カレンダー | タイトル | メモ |
|---|---|---|---|
| 泊・日勤 | 勤務用 | 番号 | 出勤時間 |
| 非番(泊の翌日に自動) | 勤務用 | `-` | 退勤時間 |
| 休日(特休・公休・年休) | 休日用 | 番号 | なし |
| 手入力(マスタにないもの) | 勤務用 | 入力した文字 | なし |

- 時間は、その日が土日祝なら「休日」、それ以外は「平日」の列を使う(祝日はGoogleの「日本の祝日」カレンダーで判定)
- 月末が泊なら翌月1日の非番も登録する
- 登録し直すと、このアプリが作った予定だけを消して作り直す(手で入れた予定は消えない)

## セットアップ

1. Googleスプレッドシートを新規作成し、「勤務コード」シートを作ってマスタを貼り付ける。
   1行目の見出しは次のとおり(列の順番は自由、「泊」列は無くてもよい)。

   | 番号 | 種別 | 平日出勤 | 平日退勤 | 休日出勤 | 休日退勤 | 泊 |
   |---|---|---|---|---|---|---|

   - 種別は `泊` / `日勤` / `休日` のどれか
   - 退勤は、泊なら翌日(非番の日)の退勤時刻、日勤ならその日の退勤時刻
   - 特休・公休・年休は種別 `休日` で時間は空欄
2. 「拡張機能」→「Apps Script」を開き、`Code.gs` と `index.html`(HTMLファイルとして追加)を貼り付ける。
   「プロジェクトの設定」で「appsscript.json をエディタで表示」をオンにし、`appsscript.json` も貼り付ける。
3. 「プロジェクトの設定」→「スクリプト プロパティ」に以下を追加する。
   - `WORK_CALENDAR_ID`: 勤務用カレンダーのID
   - `HOLIDAY_CALENDAR_ID`: 休日用カレンダーのID
   (カレンダーIDはGoogleカレンダーの各カレンダーの「設定と共有」→「カレンダーの統合」にある)
4. Googleカレンダーに「日本の祝日」が入っていなければ追加する。
5. 「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」、実行ユーザー「自分」、アクセス「自分のみ」でデプロイし、
   発行されたURLをスマホのホーム画面に追加する。
6. 初回アクセス時の権限確認で「このアプリは Google で確認されていません」と出たら、
   「詳細」→「(プロジェクト名)に移動」→「許可」で進める。

コードを直したときは「デプロイを管理」→ 編集 →「新バージョン」で更新する(URLは変わらない)。

## 個人情報

氏名・勤務先・マスタの実データ・カレンダーIDはリポジトリに含めない。
