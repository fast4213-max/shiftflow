# shiftflow

スマホから勤務を手入力し、Googleカレンダー(勤務用・休日用)に終日予定として登録する、
スプレッドシート + Google Apps Script(GAS)だけで動く個人用Webアプリです。
ライフベアへはGoogleカレンダー側の連携で反映します。

## ファイル

```
gas/Code.gs          サーバー側(シート読み書き・祝日判定・カレンダー登録)
gas/index.html       入力画面(日ごとの列を横スクロール)
gas/appsscript.json  マニフェスト(タイムゾーン・Webアプリ設定)
```

## 画面

- 上の ◀ ▶ で月を切り替える(当月より前には戻れない)
- 1日1行で、横に「日付 / 曜日 / 平休 / 番号 / メモ」。行数は月の日数(28〜31)に合わせて変わる
- 開いたときは今日の行(青)が見える位置にスクロールする
- **平/休**: 土日祝は自動で「休」。年末年始など平日でも休日の時間を使う日は、タップで切り替える(手で変えた日は青枠)
- **番号**: タップすると番号の一覧(6列のボタン)が出るので選ぶ。マスタにないもの(`変7d`、`2500` など)は「手入力」を押すと入力欄が出る。「クリア」で空にする
- 泊の番号を入れると、翌日は自動で「非番」になる(番号は選べない。平/休とメモは変えられる)
- **メモ**: 番号や平/休を選ぶと、カレンダーのメモに入る時間(泊なら出勤時間、日勤なら出勤〜退勤、非番なら退勤時間)が自動で入る。
  手で書き換えることもできる(書き換えた値は青字。番号や平/休を選び直すと自動の値に戻る)
- 「登録」を押すと、その月の入力をシートに保存してカレンダーに登録する
- 「リセット」を押して月を選び「削除」すると、その月にこのアプリで登録した予定をカレンダーから削除する
  (手で入れた予定と、画面の入力内容は消えない。もう一度「登録」すれば元に戻る。
  月末が泊なら翌月1日の非番も一緒に消える)

## 登録される予定(すべて終日)

| 種別 | カレンダー | タイトル | メモ |
|---|---|---|---|
| 泊 | 勤務用 | 番号 | 出勤時間(例: `9:01`) |
| 日勤 | 勤務用 | 番号 | 出勤〜退勤(例: `10:15〜19:02`) |
| 非番(泊の翌日に自動) | 勤務用 | `〜` | 退勤時間 |
| 休日(特休・公休・年休) | 休日用 | 番号 | なし(手で書けば入る) |
| 手入力(マスタにないもの) | 勤務用 | 入力した文字 | なし(手で書けば入る) |

- 時間は、その日が「休」なら休日、「平」なら平日の列を使う(自動判定は土日祝。祝日はGoogleの「日本の祝日」カレンダーで判定)
- メモを手で書き換えた日は、書き換えた内容がそのままメモになる
- 月末が泊なら、翌月1日の非番も登録する
- 同じ月を登録し直すと、このアプリが作った予定だけを消して作り直す(手で入れた予定は消えない)

## セットアップ手順

PCのブラウザで作業するのがおすすめ。所要時間は15分ほど。

### 1. カレンダーを用意する

1. PCで [Googleカレンダー](https://calendar.google.com/) を開く
2. 勤務用・休日用のカレンダーがまだ無ければ作る
   - 左の「他のカレンダー」の「＋」→「新しいカレンダーを作成」→ 名前(例: 勤務)を入れて「カレンダーを作成」
   - 休日用(例: 休日)も同じように作る
3. それぞれのカレンダーIDを控える
   - 左の一覧でカレンダー名にカーソルを合わせ「︙」→「設定と共有」
   - 下の方の「カレンダーの統合」にある「カレンダー ID」(`xxxx@group.calendar.google.com`)をコピー
4. 「日本の祝日」が入っているか確認する
   - 左の「他のカレンダー」に「日本の祝日」が無ければ、「＋」→「関心のあるカレンダーを探す」→「地域の祝日」→「日本の祝日」にチェック

### 2. スプレッドシートを作ってマスタを入れる

1. [Googleスプレッドシート](https://sheets.google.com/) で空白のスプレッドシートを新規作成する(名前は自由。例: 勤務登録)
2. 下のシート名「シート1」をダブルクリックして **`勤務コード`** に変える(名前は正確に)
3. マスタのCSVを取り込む
   - 「ファイル」→「インポート」→「アップロード」でCSVを選ぶ
   - 「インポート場所」は **「現在のシートを置換する」**、「区切り文字の種類」は「カンマ」
   - 「テキストを数値、日付、数式に変換する」は **オフ**(時刻や番号の形が変わらないようにするため)
   - 「データをインポート」
4. 1行目が次の見出しになっていることを確認する(列の順番は自由、「泊」列は無くてもよい)

   | 番号 | 種別 | 平日出勤 | 平日退勤 | 休日出勤 | 休日退勤 | 泊 |
   |---|---|---|---|---|---|---|

   - 種別は `泊` / `日勤` / `休日` のどれか
   - 退勤は、泊なら翌日(非番の日)の退勤時刻、日勤ならその日の退勤時刻
   - 特休・公休・年休は種別 `休日` で、時間は空欄
   - 番号を増やしたいときはこのシートに行を足すだけでよい

「勤務記録」シートは、初めて登録したときに自動で作られる(入力内容の保存用。手で触らなくてよい)。
列は「日付 / 勤務 / 日種別 / メモ」で、日種別とメモは画面で手修正した日だけ入る。

### 3. スクリプトを貼り付ける

1. スプレッドシートのメニュー「拡張機能」→「Apps Script」を開く(別タブでエディタが開く)
2. 左上の「無題のプロジェクト」をクリックして名前を付ける(例: 勤務登録)。
   これは後で権限確認の画面に出る名前になる
3. **Code.gs**
   - 左の「ファイル」にある `コード.gs` を開き、中身を全部消して `gas/Code.gs` の内容を貼り付ける
4. **index.html**
   - 「ファイル」の横の「＋」→「HTML」→ 名前に **`index`** と入れる(`.html` は自動で付く)
   - 中身を全部消して `gas/index.html` の内容を貼り付ける
5. **appsscript.json**
   - 左の歯車「プロジェクトの設定」→「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェック
   - 左の「エディタ」(`< >`)に戻ると `appsscript.json` が出ているので、中身を全部消して `gas/appsscript.json` の内容を貼り付ける
6. 上の保存ボタン(フロッピーのアイコン)で保存する

### 4. カレンダーIDを設定する

1. 左の歯車「プロジェクトの設定」を開き、一番下の「スクリプト プロパティ」→「スクリプト プロパティを追加」
2. 次の2つを追加して「スクリプト プロパティを保存」

   | プロパティ | 値 |
   |---|---|
   | `WORK_CALENDAR_ID` | 手順1で控えた勤務用カレンダーのID |
   | `HOLIDAY_CALENDAR_ID` | 手順1で控えた休日用カレンダーのID |

### 5. Webアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」
2. 「種類の選択」の歯車 →「ウェブアプリ」
3. 次のように設定して「デプロイ」
   - 説明: 自由(例: v1)
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **自分のみ**
4. 「アクセスを承認」を押し、自分のGoogleアカウントを選ぶ
5. 「このアプリは Google で確認されていません」と出たら、
   左下の「詳細」→「(プロジェクト名)(安全ではないページ)に移動」→「許可」
   (自分で作ったスクリプトなので問題ない。一度許可すれば次からは出ない)
6. 表示された「ウェブアプリ」のURL(`https://script.google.com/macros/s/.../exec`)をコピーする

### 6. スマホのホーム画面に追加する

1. コピーしたURLを自分に送るなどして、スマホのブラウザで開く
   (スマホのブラウザでも、スプレッドシートと同じGoogleアカウントにログインしておく)
2. ホーム画面に追加する
   - iPhone(Safari): 共有ボタン →「ホーム画面に追加」
   - Android(Chrome): 右上の「︙」→「ホーム画面に追加」

### 7. 動作確認

1. 1〜2日だけ番号を入れて「登録」を押す
2. Googleカレンダーに終日予定が入っていること、タイトルとメモが合っていることを確認する
3. ライフベアに反映されることを確認する
4. 問題なければ残りの日を入れて、もう一度「登録」(同じ月は何度登録し直してもよい)

## コードを直したとき

Apps Scriptのエディタで保存したあと、
「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「バージョン」を **「新バージョン」** にして「デプロイ」。
URLは変わらないので、ホーム画面のアイコンはそのまま使える。

## うまくいかないとき

| 画面に出るメッセージ | 対処 |
|---|---|
| 「勤務コード」シートがありません | シート名が `勤務コード` になっているか確認 |
| 「勤務コード」に「○○」列がありません | 1行目の見出しの文字を確認(前後の空白は無視される) |
| WORK_CALENDAR_ID / HOLIDAY_CALENDAR_ID のカレンダーが見つかりません | スクリプト プロパティの名前とカレンダーIDを確認 |
| Googleカレンダーに「日本の祝日」を追加してください | 手順1-4で「日本の祝日」を追加 |
| 画面が真っ白・権限エラー | スマホのブラウザでスプレッドシートと同じアカウントにログインしているか確認 |

## 個人情報

氏名・勤務先・マスタの実データ・カレンダーIDはリポジトリに含めない。
