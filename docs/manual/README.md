# 利用者向け説明書

画像つきの説明書の元データです。印刷用のPDF(`web/manual.pdf`)は、2026-10-09 に削除しました(使い方ページのリンクも外した)。必要になったら、`manual.html` を Chromium で印刷(A4)して作れます。

- 元の文書: `manual.html`。画面の写真は `img/`(アプリの画面は架空のデータで撮ったもの。`g-` で始まるのは実際のGoogleカレンダーの画面で、名前・メールアドレス・カレンダーID・URL・アイコンを伏せてある。どれも押す場所の赤い番号を付けた)
- Googleカレンダーの画面を撮り直すときも、個人情報(名前・メール・カレンダーID・URL・アイコン)を必ず伏せてから入れる
- 設定画面の写真(`img/settings.png`・`settings-ok.png`)は `node docs/manual/shots.mjs` で撮り直せる(Playwright が必要。架空のデータ・赤い番号つき。`web/img/manual/` にも同じものを置く)。設定画面の文を変えたら撮り直す
- 実データ(本物の社員番号・カレンダーID・アドレスなど)は入れない
