# 利用者向け説明書(PDF)

利用者に渡す、画像つきの説明書です。完成品は [`web/manual.pdf`](../../web/manual.pdf)(アプリの「使い方」ページからも開けます)。

- 元の文書: `manual.html`。画面の写真は `img/`(架空のデータで撮った画面に、押す場所の赤い印を付けたもの)
- Googleカレンダーの図は、実際の画面ではなく、押す場所を示したイメージ図(HTML と CSS で描いている)
- PDF は、`manual.html` を Chromium で印刷して作る(A4)。画面や手順を変えたときは、`manual.html` と `img/` を直して作り直し、`web/manual.pdf` を置き換える
- 実データ(本物の社員番号・カレンダーID・アドレスなど)は入れない
