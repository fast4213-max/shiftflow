shiftflow使い方(1枚まとめ)

流れは 設定で区所を選んで保存 → 勤務の番号を入れて「保存」 → メニューの「カレンダー」で見る の3ステップだけ。 Googleカレンダー連携(⑤)は、スマホの標準カレンダー・TimeTree・家族などに同期したい人だけ必要です。

① ログイン・最初の設定 最初の1回だけ・1〜2分

  • 社員番号(7桁)とPIN(4桁)でログイン。初めての人は「新規登録」(共通パスワードは管理者に聞く)
  1. 上のメニューの 設定 を開く
  2. 「1. 区所を選ぶ」で自分の区所を選ぶ(番号の一覧は区所ごとに違う)
  3. 「カレンダーの表記」は好みでチェック(なしでも可。下の表)
  4. 「Googleカレンダーにも登録する」はチェックなしのまま
  5. 一番下の 保存。「保存済みです」で完了

カレンダーの表記(後からいつでも変更可)

チェックカレンダーでの出方
出勤を2段上に番号、下に出勤時間の2本
非番を2段上に「〜」、下に退勤時間の2本
名前に時間「1(10:00)」「〜(9:00)」のように表示
時間つきタップで出勤〜退勤が出る。泊は翌日退勤まで1件

「2段」と「名前に時間」はどちらか一方で。「時間つき」がオンの間は、他の2つは使われません。

② 勤務を入力する

  1. メニューの 勤務入力。◀ ▶ で月を選ぶ(今月より前は不可)
  2. 日付の行の「選択」を押し、番号を選ぶ(一覧にないものは「手入力」、消すときは「クリア」)
  3. 月を入れ終えたら 保存 → アプリのカレンダーに出る
  • 番号を選ぶと時間(メモ)が自動で入る。手で直すと青字に
  • 泊を入れると翌日は自動で「非番」。月末が泊なら翌月1日の非番も入る
  • 土日・祝日・年末年始(12/30〜1/3)は自動で「休」
  • 同じ月は何度でも保存し直してOK。リセット でその月の入力を空にする

写真取込(勤務指定表の写真から読み取る)

  • 写真取込 → Claude(AI)のページへ。Claudeのアプリとアカウントが必要(無料可。自分の使用量を使う)
  • Android・PC: 名前・月・写真を入れて「読み取る」→ 確かめて「勤務入力に反映」
  • iPhone・iPad: 「指示文をコピー」→ Claudeアプリのチャットに写真と貼り付けて送信 → 答えの「コード」をコピー → shiftflowの「貼り付けで取込」
  • 取り込んだ日は青、時間が分からない日は黄色。確かめてから「保存」

③ shiftflowカレンダー(アプリ内)

  • メニューの カレンダー で月の画面。勤務の修正は勤務入力で
  • 自分の予定は下の ＋。繰り返し・「この回だけ」の変更もできる
  • 上のラベルのボタンで、そのラベルの予定を隠す/戻す
  • 写真は予定1つに3枚(終了1か月後に自動削除)。スタンプ・TODO・重要メモも
  • 画像にする: 設定 →「画像を作る」で月を1枚の画像に →「共有する」でLINEなどへ。「日を選ぶ」で〇だけの画像も
  • 見返せるのは過去1年まで。家族には自分のアカウントで見てもらうか、Google連携で共有

④ ホーム画面に追加(おすすめ)

  • iPhone(Safari): 共有ボタン →「ホーム画面に追加」→「追加」
  • Android(Chrome): 右上「︙」→「ホーム画面に追加」→「インストール」

iPhoneはホーム画面のアプリとSafariでログインが別(初回はもう一度ログイン)。

⑤ Googleカレンダー連携 同期したい人だけ・10〜15分

  1. 設定で「Googleカレンダーにも登録する」にチェック
  2. 「簡単設定」でカレンダー名と休日の扱いを選び、Googleでカレンダーを作る → Googleの画面で許可(IDは自動で入る)
  3. 作ったカレンダーを登録用アドレス(設定画面の「コピー」)と共有。Googleカレンダーアプリ:「≡」→設定→カレンダー名→「共有する相手」で追加
  4. 権限は上から4番目「すべての予定の詳細を変更・表示可能」
  5. 区所を確かめ 保存して接続テスト →「接続できました」で完了
  • 以後は勤務入力の 登録 でGoogleにも入る(手で入れた予定は消えない)
  • 作ったカレンダー(勤務・休日・非番の時間)は全部共有する
  • iPhone標準カレンダーで見るには: 設定 → カレンダー → アカウント →「Google」を追加し、カレンダーをオン

⑥ 困ったとき

こんなときこうする
ログインできない番号・PINを手で入力。シークレットモード不可。iPhoneは「すべてのCookieをブロック」をオフ。LINEから開いたらSafari/Chromeで開き直す
PINを忘れた管理者に再設定を頼む → 仮PINで入り「PINを変える」
番号が一覧にない区所が合っているか確認。「手入力」で入れられる
書き込めません共有の権限(4番目)・アドレス・IDの貼り間違い、全カレンダーを共有したかを確認。数分おいて再テスト
スマホに出ないカレンダーアプリで勤務用などが「表示(同期)」か確認
その他メニューの お問い合わせ(ログイン前も可。PINは書かない)
詳しくは、アプリ上のメニュー「使い方」を見てください。 2026年11月版
