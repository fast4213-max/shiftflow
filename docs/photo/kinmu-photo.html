勤務表の写真取込

勤務指定表の写真から、自分の行をClaudeが読み取ります。読み取った内容を確かめてから、shiftflow の勤務入力に反映します。

写真取込の使い方

使う前に

  • Claude のアカウントが必要です。持っていない人は claude.ai で新規登録、持っている人はログインしてから、このページを開いてください(Claude のアプリでも、スマホのブラウザでも使えます)。
  • 無料プランでも使えます。読み取りには、あなた自身の Claude の使用量を使います。shiftflow や、このページを作った人の分は使いません。
  • 何回も読み取ると、使用量の上限に達して、しばらく(最大5時間ほど)使えなくなります。その間は Claude のほかの使い方(チャットなど)もできなくなります。「読み直す」は丁寧に読むぶん、多く使います。1か月に1〜2回の読み取りで済むように使ってください。
  • 最初の読み取りで「Claude に写真を送ってよいか」の確認が出ます。「許可」を選んでください。

手順

  1. 名前を、勤務表に書かれているとおりに入れます(次からは覚えています)。
  2. 月を選び、「カメラで撮る」か「写真から選ぶ」で勤務表の写真を入れます。
  3. 「読み取る」を押します。30秒〜1分ほどかかります。
  4. 上の写真と、下の表を見比べます。違うところは番号を直します。黄色の日は読みにくかった日です。写真は2本指で拡大・縮小、ドラッグで動かせます。
  5. 変・臨時など、時間が決まっていない番号の時間(メモ)は、shiftflow の勤務入力で入れます。分からなければ「保存」しておき、あとで入れられます。
  6. 「勤務入力に反映」を押すと shiftflow の勤務入力画面が開いて、読み取った内容が入ります。確かめてから「登録」(カレンダーに入れる)か「保存」(入力だけ残す)を押します。

うまく撮るコツ

  • 自分の行と、上の日付の行が両方入るように撮ります。
  • 明るい所で、表に対してまっすぐ撮ります。影や光の反射がかからないようにします。

「勤務入力に反映」で開けないとき

「コピー」を押してから、shiftflow の勤務入力画面の「貼り付けで取込」に貼り付けます。

「勤務入力に反映」で開いた画面で shiftflow のログインを聞かれたら、一度ログインしてください。次からは聞かれません。

shiftflow をホーム画面に追加して使っている人は、写真取込のときはブラウザ(Chrome・Safari)で shiftflow を開くと、ログインし直しが少なくて済みます。

勤務表に書かれている名前で、自分の行を探します。この端末に覚えておきます。

勤務表の写真

自分の行が入るように、表全体を明るく、まっすぐ撮ってください。

読み取り中です(30秒〜1分ほど)

写真は、読み取るときにあなたのClaudeに送るだけで、このページにもサーバーにも残りません。読み取りには、あなたのClaudeの使用量を使います。くわしくは上の「写真取込の使い方」を見てください。
