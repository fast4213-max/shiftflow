勤務表の写真取込

勤務指定表の写真から、Claude のチャットで自分の行を読み取ってもらい、その答えを shiftflow の勤務入力に貼り付けます。

勤務表に書かれている名前で、自分の行を探します。この端末に覚えておきます。

手順

  1. 上で名前・月を入れて、「指示文をコピー」を押します。
  2. このページを閉じて、Claude のアプリで新しいチャットを開きます。
  3. 入力欄の左の「＋」を押し、「カメラ」で勤務表を撮るか、「写真」から選んで付けます。そのあと、入力欄に指示文を貼り付けて送ります。
  4. 返ってきた答えの「コード」と書かれた枠の右上にある、四角が2つ重なったマーク()を押すとコピーできます。自分が送った指示文の中にも同じような枠があるので、Claude の答えのほう(下の枠)を押してください。
  5. shiftflow の勤務入力画面に戻り、「貼り付けで取込」を押して、貼り付けて「取り込む」を押します。
  6. 変・臨時など、時間が決まっていない番号の時間(メモ)は、勤務入力で入れます。確かめてから「保存」を押します(アプリのカレンダーに出ます)。Googleカレンダーにも登録する人は「登録」を押します。

うまく撮るコツ

  • 自分の行と、上の日付の行が両方入るように撮ります。
  • 明るい所で、表に対してまっすぐ撮ります。影や光の反射がかからないようにします。

使う前に

  • Claude のアプリとアカウントが必要です(無料プランでも使えます)。持っていない人は、Claude のアプリを入れて新規登録してください。
  • 読み取りには、あなた自身の Claude の使用量を使います。何回も読み取ると上限に達して、しばらく(最大5時間ほど)Claude が使えなくなります。1か月に1〜2回で済むように使ってください。
  • 写真は、あなたの Claude のチャットに送るだけで、shiftflow には送りません。
  • 今月より前の月は取り込めません。取り込んだあとは、勤務入力の画面で内容を確かめてください。
