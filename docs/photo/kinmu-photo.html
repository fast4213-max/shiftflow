勤務表の写真取込

勤務指定表の写真から、自分の行をClaudeが読み取ります。読み取った内容を確かめてから、shiftflow の勤務入力に反映します。

写真取込の使い方

使う前に

  • Claude のアプリとアカウントが必要です。持っていない人は、Claude のアプリを入れて新規登録、持っている人はログインしてください。
  • 使い方は、スマホで違います。下の「Android・PC」「iPhone」から、自分のスマホを選んでください。iPhone では、このページの「読み取る」が使えないため、Claude のアプリのチャットで読み取ってもらいます。
  • 無料プランでも使えます。読み取りには、あなた自身の Claude の使用量を使います。shiftflow や、このページを作った人の分は使いません。
  • 何回も読み取ると、使用量の上限に達して、しばらく(最大5時間ほど)使えなくなります。その間は Claude のほかの使い方(チャットなど)もできなくなります。「読み直す」は丁寧に読むぶん、多く使います。1か月に1〜2回の読み取りで済むように使ってください。
  • 最初の読み取りで「Claude に写真を送ってよいか」の確認が出ます。「許可」を選んでください。
  • Android で「読み取る」がエラーになる・押せないときは、「エラーが出る・読み取れないとき」を開いてください。まずブラウザ(Chrome)で開き直す方法、それでもだめなときにチャットで読み取る方法が書いてあります。

手順(Android・PC)

  1. 名前を、勤務表に書かれているとおりに入れます(次からは覚えています)。
  2. 月を選び、「カメラで撮る」か「写真から選ぶ」で勤務表の写真を入れます。
  3. 「読み取る」を押します。30秒〜1分ほどかかります。
  4. 上の写真と、下の表を見比べます。違うところは番号を直します。黄色の日は読みにくかった日です。写真は2本指で拡大・縮小、ドラッグで動かせます。
  5. 変・臨時など、時間が決まっていない番号の時間(メモ)は、shiftflow の勤務入力で入れます。分からなければ「保存」しておき、あとで入れられます。
  6. 「勤務入力に反映」を押すと shiftflow の勤務入力画面が開いて、読み取った内容が入ります。確かめてから「登録」(カレンダーに入れる)か「保存」(入力だけ残す)を押します。

うまく撮るコツ

  • 自分の行と、上の日付の行が両方入るように撮ります。
  • 明るい所で、表に対してまっすぐ撮ります。影や光の反射がかからないようにします。

「勤務入力に反映」で開けないとき

「コピー」を押してから、shiftflow の勤務入力画面の「貼り付けで取込」に貼り付けます。

「勤務入力に反映」で開いた画面で shiftflow のログインを聞かれたら、一度ログインしてください。次からは聞かれません。

shiftflow をホーム画面に追加して使っている人は、写真取込のときはブラウザ(Chrome・Safari)で shiftflow を開くと、ログインし直しが少なくて済みます。

勤務表に書かれている名前で、自分の行を探します。この端末に覚えておきます。

iPhone では、Claude のアプリのチャットで写真を読み取ってもらい、答えを shiftflow に貼り付けます(Safari では読み取れません)。

  1. 上で名前・月を入れて、下の「指示文をコピー」を押します。
  2. このページを閉じて(左上の ✕)、Claude のアプリで新しいチャットを開きます。
  3. 入力欄の左の「＋」を押し、「カメラ」で勤務表を撮るか、「写真」から選んで付けます。そのあと、入力欄に指示文を貼り付けて送ります。
  4. 返ってきた答えの「コード」と書かれた枠の右上にある、四角が2つ重なったマーク()を押すとコピーできます。自分が送った指示文の中にも同じような枠があるので、Claude の答えのほう(下の枠)を押してください。
  5. shiftflow の勤務入力画面に戻り、「貼り付けで取込」を押して、貼り付けて「取り込む」を押します。

Claude のアプリが無い人は、App Store で「Claude」を入れてログインしてください。shiftflow の「写真取込」を押すと、Claude のアプリでこのページが開きます。読み取りには、あなた自身の Claude の使用量を使います。

エラーが出る・読み取れないとき

まず試すこと: ブラウザで開き直す

Claude のアプリでは読み取れないことがあります。そのときは、ブラウザ(Chrome)で開き直すと読み取れることがあります。

  1. Chrome で claude.ai を開いて、ログインします(アプリでログインしていても、ブラウザは別です)。
  2. 同じブラウザのアドレス欄に、次のアドレスを貼り付けて開きます。
    https://claude.ai/artifact/GivZHYnUXZoz4uqc9dWdXV
  3. 名前・月・写真を入れて、「読み取る」を押します。

それでもだめなとき: チャットで読み取る

Claude のアプリを開いて、チャットで読み取ってもらいます。その答えを shiftflow に貼り付けます。

  1. 上で名前・月を入れて、下の「指示文をコピー」を押します。
  2. Claude のアプリを開いて新しいチャットを作ります。入力欄の左の「＋」から「カメラ」か「写真」を選んで勤務表の写真を付け、指示文を貼り付けて送ります。
  3. 返ってきた答えの「コード」と書かれた枠の右上にある、四角が2つ重なったマーク()を押すとコピーできます。自分が送った指示文の中にも同じような枠があるので、Claude の答えのほう(下の枠)を押してください。
  4. shiftflow の勤務入力画面で「貼り付けで取込」を押し、貼り付けて「取り込む」を押します。

この方法でも、あなた自身の Claude の使用量を使います。取り込んだあとは、勤務入力の画面で内容を確かめてください。

写真は、読み取るときにあなたのClaudeに送るだけで、このページにもサーバーにも残りません。読み取りには、あなたのClaudeの使用量を使います。くわしくは上の「写真取込の使い方」を見てください。
