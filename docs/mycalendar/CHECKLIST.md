## 1. 保存だけの経路と「Googleにも登録する」チェック(2026-11-02 実装)
- [x] migration `20261102000000_google_sync.sql`: `user_settings.google_sync`(初期値 true)。カレンダーIDが空の既存の人は false。利用者が書ける列に追加
- [x] サーバー `register-month`: チェックを外している人は「登録」も保存だけ(Googleに何も書かない)。値がない・true は今までどおり登録する(`googleSyncOn`)
- [x] サーバー `delete-month`: チェックを外している人は、入力内容だけ消す(Googleの予定は消さない・接続テスト不要)
- [x] 設定画面: 「Googleカレンダーにも登録する」のチェック。外すとGoogle用の設定をたたみ、ボタンは「保存」(IDも接続テストも要らない)。IDは消えない。新しく使い始める人は外した状態から
- [x] 勤務入力: チェックを外している人は「登録」を隠し「保存」だけ。接続テストの案内を出さない。確認・メッセージの言葉も「保存」に
- [x] `isReady`: チェックを外している人は、区所だけで勤務入力に進める
- [x] ログイン画面の「勤務を入力して、Googleカレンダーに登録します。」を削除
- [x] テスト: Deno 206件(`googleSyncOn` を足した)・画面(Chromium)全部通過(新しく6項目)・DB assert 通過(権限と初期値)
- [ ] 本番に反映して、今の利用者(チェックが入ったまま)の「登録」「リセット」が今までどおりか確かめる(4-3 に足す)
- [ ] README・使い方ページ(`help.html`)の、Googleカレンダー前提の文言を直す
