出退勤時刻一覧表(写真・PDF)を、shiftflow のマスタ取り込み用CSVに変換してください。速さより正確さを優先し、読めない所は推測せず空欄にして、最後にまとめて質問してください。

# 出力形式
1行目は次の見出し(文字を変えない):
番号,種別,平日出勤,平日退勤,休日出勤,休日退勤,泊,平休出勤,平休退勤,休平出勤,休平退勤,翌休泊
- 全行12列にそろえる
- 時刻は H:MM(先頭ゼロなし、かっこなし)
- 種別は 泊 / 日勤 / 休日 のどれか

# 表の読み方
形1(平日・休日の2ブロック):
- 平日は番号・出勤・退勤(かっこ付き)・泊を使う
- 休日(赤字)は出勤・退勤を使う
- 勤務時間の欄は使わない

形2(平〜平・平〜休・休〜休・休〜平の4ブロック):
- 平〜平は平日の出勤・退勤、休〜休は休日の出勤・退勤にする
- 灰色や空のマスは空欄にする
- 特記事項は使わない

共通:
- 番号のかっこ書きは外す(51(日勤)→51)
- 日勤、または泊地が「−」なら種別は日勤。駅名があれば泊
- 退勤のかっこ時刻は、泊なら翌日(明け)の退勤。そのまま退勤列に入れる
- 平日だけで休日欄が空の番号は、休日を空欄のままにする
- 出勤予備(出予1など)で時刻が1組だけの枠は、平日・休日の両方に同じ時刻を入れる
- 表にない番号は作らない

# 例外の4列(平休・休平)
- 通常の時刻と1つでも違う行だけ入れる
  - 平休の通常は「平日出勤+休日退勤」
  - 休平の通常は「休日出勤+平日退勤」
- 同じなら空欄にする。形2は全行に載っているが、載っているだけでは入れない
- 出勤と退勤はセットで入れる
- 日勤と休みの行は常に空欄
- 違う行は、例外と決める前に数字の読み違いを画像で確かめる

# 翌休泊
- 泊の翌日が土休日のときだけ泊地が変わる行路が対象
- 欄外の注記(「○○泊り」)や※印を見て、そのときの泊地を入れる
- 「泊」列は通常の泊地のままにする
- 印も注記も無い行は空欄。印があるのに注記が読めないときは空欄にして質問する

# 並び順と追加行
並び順: 数字の番号(数として昇順)→数字でない番号(表の順)→変7d→特休→公休→年休
- 並べ替えはコードが使えればコードで行い、前後で件数と中身が同じことを確かめる

表のあとに次の4行を足す:
変7d,日勤,9:00,17:45,,,,,,,,
特休,休日,,,,,,,,,,
公休,休日,,,,,,,,,,
年休,休日,,,,,,,,,,
- 表に変7dがあれば表の時刻を使う。固定の時刻と違えば報告する

# 手順
1. 形1か形2かを判定し、行数と番号を先に把握する
2. 番号で対応させて1行ずつ読む
3. 例外と翌休泊を確認する
4. 並べ替え → 固定行を追加 → CSV保存
5. 元画像と見比べる(1/7、3/8、5/6、0/9、平日/休日の取り違え)
6. 次を報告する:
   - 件数(表○件+変7d+休み3件)
   - 例外を入れた行
   - 翌休泊を入れた行
   - 空欄にした所や自信がないセル
   - 並べ替えたこと
   - 画像から読んだ場合は、一度目で確認してほしいこと

CSVは master.csv というファイルで渡してください。ファイルを作れないときは、コードブロックで出してください。
