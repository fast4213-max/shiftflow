# 交番表から休みを自動入力(設計・第2版)

状態: **実装済み・未反映(2026-11-05。ブランチ `ccr-28bdd29d-n83bm3`。main にはまだ入れていない)**。7章は本人が決めた。テスト: `docs/kouban/test/kouban.test.mjs`(計算9件)・`docs/contact/test/e2e.mjs` の「交番表」(画面5項目)・`db_assert.sql`(列の権限と check)

公開リポジトリなので、交番表の中身・名前は置かない(第2版は、そもそも交番表のデータを持たない)。

## 0. 設計変更(第1版 → 第2版)

| | 第1版(やめた) | 第2版 |
|---|---|---|
| 入れるもの | 行路(①〜⑩ → 行路番号)と休み | **休みだけ** |
| 交番表のデータ | 管理画面で切替日ごとに JSON を登録(DB `kouban_tables`) | **要らない**。本人が自分の休みの並びをタップで覚える |
| マスタ・管理画面 | 行路番号をマスタで引く・管理画面に交番表の登録 | 管理画面は**増えない**。マスタは、入れるときに番号を合わせる(全角など)のに読むだけ |
| 使える区所 | 天王寺車掌区だけ | **全部の区所**(区所ごとのデータが無いので、どこでも使える) |
| ダイヤ改正 | 管理者が新しい交番表を入れ、本人は位置を選び直す | 並びが変わったら、本人が設定でタップし直す |
| 予備・M組 | 名前の欄の月の表示から自動 | **本人が予備の月を選ぶ**(例 2・5・8・11) |

変えた理由(本人): 行路は毎回変わり、ダイヤ改正のたびの入れ直しも大変。休みだけなら楽で、区所を限らずに使える。

休みだけなら並び1つで足りる理由: 天王寺車掌区の交番表(30行 × 30日)は、どの行も1行目を1列ずつずらしたもの。組(特1・特2・特予…)で変わるのは行路だけで、**休みの日は組に関係なく同じ**。だから自分の行の並びを1つ覚えれば、先の月も計算できる。

## 1. やりたいこと

- 勤務入力の「写真取込」の左に **「交番表」** ボタンと **「⚙」**(交番表の設定)を置く。**全員に出す**
- ⚙ で、カレンダーの休みの日をタップして、自分の休みの並びを覚える
- 「交番表」を押すと、表示している月の休みの日に休みを入れる(まだ保存・登録しない。保存・登録は本人)

## 2. 設定(⚙ のダイアログ)

上から順に並べる。

| 項目 | 内容 | はじめ |
|---|---|---|
| 始まりの日 | 日付を選ぶ。ここから一周分(下の日数)のカレンダーを出す | 今月の1日 |
| 一周の日数 | 何日で同じ並びに戻るか(7〜99。区所によって30日でないため、本人が入れる) | 30(天王寺車掌区の交番表) |
| 休みの並び | カレンダーの日を**タップするたびに休みが切り替わる**(なし → 特休 → 公休 → なし)。「全部消す」のボタンもある | 空 |
| 予備の月 | 1〜12月のボタンから選ぶ(いくつでも。ふつうは4つ。例 2・5・8・11)。M組も同じに扱うなら、ここで選ぶ | 無し |
| 予備の月に | 「休みを入れる」/「何もしない」 | 休みを入れる |

- **切り替わる休みは特休・公休の2つだけ**(どの区所も同じ。`OFF_ORDER`。本人が決定)。マスタは見ない。前に入れた「特公」などは、タップすると なし に戻る
- ダイアログの上に、切り替わる順番(「なし → 特休 → 公休 → なし」)を出す
- 休みは種類を分けて覚える(特休・公休。本人が決定。7章の1)
- カレンダーは始まりの日から一周分を、月をまたいで出す(2月のように短い月でもそろう。7章の4)。日付・曜日を出す。月の変わり目に線
- 休みの元は**交番表(PDF)の自分の行**から取る。実際の勤務指定表(年休などで変わっている)から取ると、次の月からずれる(ダイアログと使い方に書く)
- 予備の月は年ごとに同じ(交番表の「特予 2.5.8.11」のように)として、月の番号だけ覚える
- 「保存」で DB に保存。「やめる」で何も変えない

## 3. 入れ方(勤務入力の「交番表」)

1. 並びがまだ無ければ ⚙ を開く(「先に休みの並びを入れてください」)
2. 表示している月の日ごとに、`(日付 − 始まりの日) mod 一周の日数` で並びのどこかを出し、そこに休みがあればその休みを入れる候補にする(始まりの日より前の日も、同じく繰り返す)
3. 予備の月で「何もしない」なら何も入れず、「◯月は予備の月なので入れません(⚙ で変えられます)」と出す
4. 確認: 「◯月に休みを◯日分入れます。休みの日だけ上書きし、ほかの日はそのままです。(◯日・◯日は今の番号を休みに変えます)(まだ保存・登録はしません)」
5. 入れる → 本人が「保存」か「登録」

入れ方の決まり

- **休みの日だけ上書き**。ほかの日(自分で入れた行路など)はそのまま(7章の2)。上書きする日はメモも空にする(番号を選び直したときと同じ)
- **非番の日(前日が泊)は入れない**(登録してもサーバーが非番の日の番号は使わないため)。入れなかった日はメッセージで知らせる(「◯日は非番なので入れませんでした」)
- 入れた休みの番号は、写真取込と同じく一覧の番号に合わせる(`masterCodeOf`。全角など)。一覧に無い休みの番号は、写真取込と同じく「登録すると勤務用カレンダーに入る」と知らせる
- 休みを入れて泊が非番でなくなることは無い(休みは泊の前の日にしか関わらない)。入れたあとは `codeChanged` と同じ片付けをする
- 入れた日は写真取込と同じく色を付ける
- **月ごと**(表示している月だけ)。何か月分をまとめて入れる形にはしない(見ていない月の入力を上書きし、Google への登録も何か月分も一度に走るため。7章の3)

## 4. 覚える場所

`user_settings` に列を1つ足す(本人だけが読み書き。スマホと PC で同じになるように)。

```json
{ "start": "2026-11-01", "cycle": 30, "days": { "3": "特休", "4": "公休", "15": "特休" }, "spareMonths": [2, 5, 8, 11], "spareOff": true }
```

- `days` は「始まりの日から何日目(0から)」→ 休みの番号。休みの無い日は入れない
- 確かめ(画面と DB): `start` は日付、`cycle` は 7〜99、`days` の日は 0〜cycle−1・番号は30文字まで、`spareMonths` は 1〜12。列は 4KB まで(DB の check)
- 管理者用の表・関数は作らない。第1版の `kouban_tables`・`save_kouban`・`delete_kouban`・管理画面の交番表は外す(本番に出していないので、migration は書き直す)

## 7. 決めたこと(2026-11-05 本人)

1. 休みは**種類を分けて**入れる(特休・公休)
2. すでに入っている日は、**休みの日だけ上書き**。ほかの日はそのまま
3. **月ごと**に入れる(表示している月。保存・登録は本人)
4. タップのカレンダーは、**始まりの日を選んで一周分**を出す
5. **天王寺車掌区だけにしない**。全部の区所で使える
6. **一周の日数は設定で入れる**(30日ごとでない区所があるため。はじめ 30)
7. 休みは**タップするたびに切り替わる**(なし → 特休 → 公休 → なし)。1回設定すれば終わりなので。タップに出すのは**特休・公休だけ**
8. 一周の日数は 7〜99日
