# 交番表から休みを自動入力(設計・第2版)

状態: **設計中(2026-11-05 設計変更)**。コードはまだ第1版(ブランチ `ccr-28bdd29d-n83bm3`。main には入れていない)。7章の「決めること」が決まったら、第2版で作り直す

公開リポジトリなので、交番表の中身・名前は置かない。

## 0. 設計変更(第1版 → 第2版)

| | 第1版(やめた) | 第2版 |
|---|---|---|
| 入れるもの | 行路(①〜⑩ → 行路番号)と休み | **休みだけ** |
| 交番表のデータ | 管理画面で切替日ごとに JSON を登録(DB `kouban_tables`) | **要らない**。本人が自分の休みの並び(30日)をタップで覚える |
| マスタ・管理画面 | 行路番号をマスタで引く・管理画面に交番表の登録 | **使わない・増えない** |
| ダイヤ改正 | 管理者が新しい交番表を入れ、本人は位置を選び直す | 並びが変わったら、本人が設定でタップし直す |
| 予備・M組 | 名前の欄の月の表示から自動 | **本人が予備の月を選ぶ**(例 2・5・8・11) |

変えた理由(本人): 行路は毎回変わり、ダイヤ改正のたびの入れ直しも大変。休みだけなら楽。

なぜ休みだけなら並び1つで足りるか: 交番表(30行 × 30日)は、どの行も1行目を1列ずつずらしたもの。組(特1・特2・特予…)で変わるのは行路だけで、**休みの日は組に関係なく同じ**。だから自分の行の30日の並びを1つ覚えれば、先の月も計算できる。

## 1. やりたいこと

- 勤務入力の「写真取込」の左に **「交番表」** ボタンと **「⚙」**(設定)。区所の名前に「天王寺車掌区」が入っている人だけに出す
- ⚙ で、カレンダーの休みの日をタップして、自分の休みの並び(30日)を覚える
- 「交番表」を押すと、表示している月に休みを入れる(まだ保存・登録しない。保存・登録は本人)

## 2. 設定(⚙)

| 項目 | 内容 |
|---|---|
| 休みの並び | カレンダー(30日分)を出して、休みの日をタップ。始まりの日と30日分を覚える(7章の1・4) |
| 予備の月 | 1〜12月から選ぶ(いくつでも。ふつうは4つ。例 2・5・8・11)。M組も同じに扱うなら、ここで選ぶ |
| 予備の月に | 「休みを入れる」/「何もしない」 |
| 並びのやり直し | ダイヤ改正などで並びが変わったら、タップし直す |

- 休みの元は**交番表(PDF)の自分の行**から取る。実際の勤務指定表(年休などで変わっている)から取ると、次の月からずれる(使い方にも書く)
- 予備の月は年ごとに同じ(交番表の「特予 2.5.8.11」のように)として、月の番号だけ覚える

## 3. 入れ方(勤務入力の「交番表」)

1. 設定がまだなら ⚙ を開く
2. 表示している月の日ごとに `(日付 − 始まりの日) mod 30` で並びのどこかを出し、休みの日に休みの番号を入れる
3. 予備の月で「何もしない」なら何も入れない(そう知らせる)
4. 確認(「◯月に休みを◯日分入れます」)→ 入れる → 本人が「保存」か「登録」

- **月ごと**(表示している月だけ)。何か月分をまとめて入れる形にはしない。見ていない月の入力を上書きし、Google への登録も何か月分も一度に走るため(本人と相談。2026-11-05)
- 入れた日は写真取込と同じく色を付ける
- 番号は `masterCodeOf` で一覧の番号に合わせる(全角など)。一覧に無い休みの番号は、写真取込と同じくメッセージで知らせる

## 4. 覚える場所

`user_settings` に列を1つ足す(本人だけが読み書き。スマホと PC で同じになるように):

```json
{ "start": "2026-10-01", "days": ["特休", "", "", "公休", "…(30個)"], "spareMonths": [2, 5, 8, 11], "spareOff": true }
```

- `days` は30個。空は「何も入れない日」
- 管理者用の関数・表は作らない。第1版の `kouban_tables`・`save_kouban`・`delete_kouban`・管理画面の交番表は外す(本番にはまだ出していないので、migration は作り直す)
- 列の大きさは小さく(4KB まで)制限する

## 6. 予想されるバグと対策

| # | 起きそうなこと | 対策 |
|---|---|---|
| KB1 | 2月(28日)など30日に足りない月で並びをタップする | タップのカレンダーは「始まりの日から30日」を出す(月をまたいで出す) |
| KB2 | 実際の勤務指定表から休みをタップして、並びがずれる | 設定と使い方に「交番表の自分の行から」と書く |
| KB3 | ダイヤ改正で並びが変わったのに古い並びのまま | 使い方に書く。並びの始まりの日を設定に出す |
| KB4 | 予備の月を選び忘れる | 設定に予備の月を出しておく(選ばなくても使える) |
| KB5 | 休みの番号が一覧(マスタ)に無い | 写真取込と同じく、登録で勤務用カレンダーに入ると知らせる |
| KB6 | 登録・保存の途中に押す | 写真取込と同じく断る |

## 7. 決めること(本人に確認中)

1. 休みの種類: 特休・公休・特公を分けて入れるか(タップのたびに 特休 → 公休 → 特公 → なし)、全部同じ番号(例 公休)か
2. すでに入っている日: **すすめ: 休みの日だけ上書き、ほかの日はそのまま**(自分で入れた行路を消さないため)。または月を丸ごと置き換え
3. 「何月から何月まで」: 何か月分をまとめて入れる意味なら、上のとおり月ごとにする。「この並びを何月まで使う(ダイヤ改正まで)」の意味なら、設定に「使う期間」を足す
4. タップのカレンダー: 始まりの日を選んで30日分を出す(案)。または「今月の1日から30日」で決め打ち
