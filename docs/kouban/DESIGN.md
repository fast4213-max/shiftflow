# 交番から休みを自動入力(設計)

状態: **実装済み・本番に反映(2026-11-05)**。決めたことは6章(本人)。テスト: `docs/kouban/test/kouban.test.mjs`(計算9件)・`docs/contact/test/e2e.mjs` の「交番表」(画面5項目。`ONLY=交番表` で流せる)・`db_assert.sql`(列の権限と check)

公開リポジトリなので、交番表の中身・名前は置かない(このしくみは交番表のデータを持たない)。

## 1. やりたいこと

- 勤務入力の「写真取込」の左に **「交番」** と **「⚙」**(交番の設定)。**全部の区所**の人に出す
- ⚙ で、カレンダーの休みの日をタップして、自分の休みの並び(一周分)を1回だけ覚える
- 「交番」を押すと、表示している月の休みの日に休みを入れる(まだ保存・登録しない。保存・登録は本人)

休みだけなら並び1つで足りる理由: 交番表(天王寺車掌区は 30行 × 30日)は、どの行も1行目を1列ずつずらしたもの。組(特1・特2・特予…)で変わるのは行路だけで、**休みの日は組に関係なく同じ**。だから自分の行の並びを1つ覚えれば、先の月も計算できる。

## 2. 設定(⚙ のダイアログ「交番の設定」)

上から順に:

| 項目 | 内容 | はじめ |
|---|---|---|
| 説明 | 交番の自分の行を見て休みをタップ。実際の勤務指定表(年休などが入っている)からではなく交番から | — |
| 一周の日数 | 何日で同じ並びに戻るか(7〜99。区所によって30日でないため) | 30 |
| 入力する月 | カレンダーを出す月(月を選ぶ欄) | 勤務入力で表示している月 |
| 赤字 | 「※本番の月で入力してください。」 | — |
| 休みの並び | 入力する月の1日から一周分のカレンダー(月をまたぐ。曜日をそろえる)。日を**タップするたびに なし → 特休 → 公休 → なし**。「全部消す」 | 空 |
| 予備の月 | 「予備の月も休みを入れる」/「予備の月は何もしない」。**何もしないのときだけ**、1〜12月のボタンを出して何もしない月を選ぶ(例 2・5・8・11)。M組なども、ここで選ぶ | 休みを入れる |

- タップに出る休みは**特休・公休だけ**(どの区所も同じ。`OFF_ORDER`)。前に入れた別の番号は、タップすると なし に戻る
- 入力する月・一周の日数を変えても、タップした**本当の日付**の休みはそのまま(`moveStart`)。一周を短くして休みが外に出るときは、確かめてから消す(`fitCycle`)
- 「休みを入れる」で保存したときは、予備の月は覚えない(使わないため)
- 保存すると、始まりの日 = 入力する月の1日 として覚える

## 3. 入れ方(勤務入力の「交番」)

1. 並びがまだ無ければ「先に「⚙」で、交番の休みを入れてください。」と出して ⚙ を開く
2. 表示している月が予備の月で「何もしない」なら、何も入れずに「◯月は予備の月なので、休みは入れません。「⚙」で変えられます。」
3. 日ごとに `(日付 − 始まりの日) mod 一周の日数` で並びのどこかを出し、休みがあれば入れる(始まりの日より前の日も繰り返す)
4. 確認: 「◯年◯月に、交番で設定した休みを◯日分入れます。休みの日だけ上書きし、ほかの日はそのままです。」+ あれば「今の番号を休みに変える日: ◯日」「非番なので入れない日: ◯日」。**括弧は使わない**
5. OK → 画面に入れる → 本人が「保存」か「登録」

決まり:

- **休みの日だけ上書き**。ほかの日(自分で入れた行路など)はそのまま。上書きした日のメモは自動の値に戻す
- **非番の日(前日が泊)には入れない**(登録してもサーバーが非番の日の番号は使わないため)。入れなかった日はメッセージで知らせる
- 番号は一覧の番号に合わせる(`masterCodeOf`。全角など)。一覧に無い休みは、写真取込と同じく「登録すると勤務用カレンダーに入る」と知らせる
- 入れたあとは `codeChanged` と同じ片付け。入れた日は写真取込と同じく色を付ける
- **月ごと**(表示している月だけ)。次の月には触らない。何か月分をまとめて入れる形にはしない(見ていない月を上書きし、Google への登録も一度に走るため)

## 4. 覚える場所

`user_settings.kouban`(jsonb。本人だけが読み書き。migration `20261105000000_kouban.sql`):

```json
{ "start": "2026-11-01", "cycle": 30, "days": { "2": "特休", "3": "公休" }, "spareMonths": [2, 5, 8, 11], "spareOff": false }
```

- `days`: 始まりの日から何日目(0から)→ 休みの番号。`spareOff`: 予備の月も休みを入れるか
- DB は形(オブジェクト)と大きさ(4KB)だけ見る。中身の確かめは `web/js/kouban.js` の `readKouban`(おかしな値は捨てる)
- 管理者の表・関数・管理画面は無い

## 5. 予想されるバグと対策

| # | 起きそうなこと | 対策 |
|---|---|---|
| KB1 | 実際の勤務指定表から休みをタップして、次の月からずれる | ダイアログと使い方に「交番から」、赤字で「本番の月で入力」 |
| KB2 | ダイヤ改正で並びが変わったのに古いまま | 使い方に書く。⚙ を開けば表示している月の休みが出るので見比べられる |
| KB3 | 休みの番号がマスタに無い | 入れた文字のまま入り、一覧に無い休みとして知らせる |
| KB4 | 休みの日が非番の日に当たる | 入れずに知らせる |
| KB5 | 登録・保存の途中・読み込み中に押す | 写真取込と同じく断る |
| KB6 | 一周を短くして休みが外に出る | 確かめてから消す。やめると元のまま |
| KB7 | 区所を変えた | 並びはそのまま使える(番号は KB3 と同じ) |
| KB8 | 狭い画面(320px) | ボタンは折り返す。e2e で確かめる |

## 6. 決めたこと(2026-11-05 本人)

1. **休みだけ**入れる(行路は入れない)。交番表のデータ・マスタの行路・管理画面は使わない(行路は毎回変わり、ダイヤ改正のたびの入れ直しが大変なため)
2. **全部の区所**で使う
3. 休みは**特休・公休**を分けて、**タップするたびに切り替わる**(1回設定すれば終わりなので)
4. すでに入っている日は、**休みの日だけ上書き**
5. **月ごと**に入れる(表示している月。次の月には触らない)
6. **一周の日数は設定で入れる**(7〜99日。30日でない区所がある)
7. ボタンは「**交番**」。設定に始まりの日の欄は置かず、**入力する月**を選び、その下に赤字で「**※本番の月で入力してください。**」
8. 予備の月のボタンは「**何もしない**」のときだけ出す
9. 確認の文は「交番で設定した休みを◯日分入れます」。括弧は使わない
