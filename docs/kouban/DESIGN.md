# 交番表から自動入力(設計)

状態: **実装済み・未反映(2026-11-05。ブランチ)**。5章は本人が決めた(2026-11-05)。テスト: `docs/kouban/test/kouban.test.mjs`(計算)・`docs/contact/test/e2e.mjs` の「交番表」(画面)・`db_assert.sql`(権限)

公開リポジトリなので、交番表の中身(マス・行路番号・泊地・名前)はリポジトリに置かない。管理画面から DB に入れる。

## 1. やりたいこと

天王寺車掌区の交番表(PDF)から、自分の位置を選ぶだけで、その月の勤務(泊〜非番〜休休…)を勤務入力に入れる。

- 勤務入力の「写真取込」の左に **「交番表」** ボタン。区所の名前に「天王寺車掌区」が入っている人だけに出す
- となりに **「交番表の設定」**(歯車)。自分の位置・休みだけか行路もか・予備のときに休を入れるか
- 名前は使わない(DB にも入れない)。自分の位置は、名前を抜いた表で**自分のマスをタップ**して決める

## 2. 交番表の読み方(PDF)

| 部分 | 中身 | 使い方 |
|---|---|---|
| 右上の日付の表(13行) | 1行 = 30日。1行目の1列目が 2026年10月1日、2行目の1列目が10月31日…と30日ずつ続く。丸の数字(⑪など)はその月の1日 | 日付 → 列: `(日付 − 始まりの日) mod 30` |
| 真ん中のマス(30行 × 30列) | ①〜⑩(泊。次の列は空 = 非番)・特・公・特公・空 | 自分の行の、その日の列のマス |
| 名前の欄(左3列・M組・右3列) | 列ごとに「特1 3.6.9.12 / 特2 1.4.7.10 / 特予 2.5.8.11」のように、**何月にどの組か** | 日付の月(1日から末日)で組を決める |
| 下の表(特1・特2・近1・近2・組外) | 組の ①〜⑩ → 行路番号・泊地・時間 | 行路番号を勤務入力の番号にする(時間はマスタから) |

- 行は 30行(上の1〜15・下の1〜15)。今の表は、どの行も1行目を1列ずつずらしたもの(どの行もマスは30日で 泊10・非番10・特4・公4・特公2)
- 組が変わるのは月の1日(日付の表の行の切れ目ではない)。泊・非番の並びは組に関係なく同じなので、月末の泊の翌日(1日)は非番のまま
- 予備(特予・近予)と M組は、①〜⑩ に関係なく休みだけ入れる(5章の2)

## 3. しくみ

| 部分 | どこ | 内容 |
|---|---|---|
| 交番表のデータ | DB `kouban_tables`(マスタの切替日 `master_periods` ごとに1つ) | 4章の JSON。読むのは利用者全員(区所の名前で絞るのは画面)、書くのは管理者の関数だけ。切替日を消すと一緒に消える |
| 登録 | 管理画面の「マスタ」タブ(天王寺車掌区の区所だけ)。切替日を選んで、JSON を貼る・ファイルを選ぶ → 確認 → 入れる。同じ切替日の、名前に「天王寺車掌区」を含むほかの区所にもまとめて入れられる | PDF から JSON を作るのは Claude に頼む(このリポジトリには置かない) |
| 計算 | `web/js/kouban.js`(画面に関係しない部分。`docs/kouban/test/kouban.test.mjs` で確かめる) | 確かめ(`checkKouban`)・日ごとの番号(`koubanDays`) |
| 自分の位置・設定 | `user_settings.kouban`(jsonb) | `{ "pos": { "<切替日のid>": { "r": 行, "c": 名前の欄 } }, "routes": true, "spareOff": true }`。位置は切替日ごと(ダイヤ改正で行が変わることがあるため) |
| 入力 | `web/js/input.js` | 写真取込と同じく、確認のあとその月を置き換える(まだ保存・登録しない)。番号は `masterCodeOf` で一覧の番号に合わせる(「1」→ 一覧の「特1」も) |

### ダイヤ改正・ダイヤ修正(3月・10月)

- 交番表は**マスタの切替日ごと**に持つ。日ごとに、その日のマスタ(`masterOn`)の切替日の交番表を使う。だから3月の途中で切り替わっても、切替日より前は前の交番表、後は新しい交番表になる
- 新しい切替日の交番表がまだ入っていない日は**入れない**(前の交番表で続けて作ると、違う勤務が入るため)。その日は今の入力を残し、「◯日から(◯◯)の交番表がまだありません」と出す
- 自分の位置も切替日ごとに覚える。新しい交番表の位置をまだ選んでいなければ、その月に交番表を使うときに選んでもらう
- 切替日の前日の泊は、今までどおり(泊の日は前のマスタ、非番の退勤は新しいマスタ。plan.js)

## 4. データ(管理画面に貼る JSON)

```json
{
  "v": 1,
  "start": "2026-10-01",
  "days": 30,
  "rows": ["1", "2", "…", "15", "1", "…", "15"],
  "cells": [["①", "", "②", "", "特", "公", "…"], ["特公", "①", "…"]],
  "cols": [
    { "label": "特急1", "groups": { "1": "特2", "2": "特予", "3": "特1", "…": "…" } },
    { "label": "M組", "groups": { "1": "M組", "…": "…" } }
  ],
  "routes": { "特1": { "①": "42", "②": "2" }, "特2": { "①": "15" } },
  "off": { "特": "特休", "公": "公休", "特公": "特公" }
}
```

- `start`: 1列目の日。`days`: 列の数(繰り返しの日数)。`rows`: 行の見出し(画面に出す)。`cells`: 行ごとのマス(`days` 個ずつ)
- `cols`: 名前の欄(左から)。`groups` は月(1〜12)→ 組。12か月全部要る
- `routes`: 組 → 丸の数字 → 行路番号。**`routes` に無い組は予備**(休みだけ)。M組もここに入れない
- `off`: 休みのマス → 勤務入力の番号
- 確かめ(`checkKouban`): v=1・日付・`days` 1〜62・行 1〜60・マスの数・名前の欄 1〜12・12か月・マスの文字は丸の数字か `off` にあるか空・丸の数字が乗務の組の `routes` に全部ある・文字の長さ(番号30文字・見出し20文字)。全体 100KB まで(DB でも見る)
- 今の PDF から作った JSON は、本人に渡した(コミットしない)

## 5. 決めたこと(2026-11-05 本人)

1. 「特公」のマスは「特公」のまま入れる(一覧の番号に合わせる)。「特」→ 特休、「公」→ 公休
2. M組は予備と同じ(休みだけ。①〜⑩ は入れない)
3. その月は丸ごと置き換える(写真取込と同じ。確認してから。保存・登録は本人)。交番表の無い日(ダイヤ改正の後でまだ入っていない日)は今の入力を残す
4. 交番表は管理画面で登録する(リポジトリには置かない)。名前は入れない
5. 設定: 「行路も入れる / 休みだけ入れる」・「予備・M組のとき休を入れる」(チェック)。はじめは「行路も入れる」「休を入れる」

## 6. 入れ方(勤務入力)

1. 「交番表」を押す。この月に使う交番表で、位置をまだ選んでいなければ、位置を選ぶ画面を出す
2. 位置を選ぶ画面: 名前の無い表(行の見出し × 名前の欄)。欄の上に、**この月の組**(例「特1」「特予」)を出す。自分のマスをタップ → 下に、その月の自分の並び(1日〜末日の番号)を出して確かめる → 「この位置にする」
3. 確認(「11月に交番表の内容(◯日分)を入れます。この月の今の入力は置き換わります」)→ 入れる → 「保存」か「登録」は本人
4. 入れた日は写真取込と同じく色を付ける。一覧(マスタ)に無い番号はメッセージに並べる

| 日のマス | 乗務の組(特1・特2・近1・近2) | 予備・M組 |
|---|---|---|
| ①〜⑩ | 行路も: 行路番号 / 休みだけ: 空 | 空 |
| 特・公・特公 | 特休・公休・特公 | 「休を入れる」なら同じ、外せば空 |
| 空(非番など) | 空(泊の翌日は自動で非番) | 空 |

## 7. 予想されるバグと対策

| # | 起きそうなこと | 対策 |
|---|---|---|
| KB1 | 位置を選んだあと管理者が行の少ない表を入れ直し、位置が表の外になる | 位置が表の外なら、選び直してもらう |
| KB2 | 月の途中で切替日があり、片方の交番表しか無い | 無い側の日は今の入力を残し、メッセージで知らせる |
| KB3 | 行路番号がマスタに無い(新しいマスタの CSV が未登録など) | 手入力として入り、写真取込と同じく「一覧にない番号」に並ぶ |
| KB4 | 月末の泊の翌日(翌月1日)| 勤務入力の今の仕組み(翌月1日の非番)がそのまま効く。交番表で翌月を入れると、1日のマスは空(非番)なので重ならない |
| KB5 | 登録・保存の途中に押す | 写真取込と同じく断る |
| KB6 | 過ぎた月 | 勤務入力は今月より前に戻れないので起きない |
| KB7 | 区所を天王寺車掌区以外に変えた | ボタンを出さない(位置の設定は残すが使わない) |
