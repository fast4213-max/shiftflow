# 改善提案書(shiftflow)

`kaizen-teian.pdf` は A4 1枚の改善提案書。`make_pdf.py` で作る(本文の文言もこのファイルにある)。

```sh
pip install reportlab qrcode
python3 docs/proposal/make_pdf.py                       # リポジトリに置く版(共通パスワードの欄は空)
SF_COMMON_PASSWORD=<共通パスワード> python3 docs/proposal/make_pdf.py 印刷用.pdf   # 印刷用。コミットしない
```

- 公開リポジトリなので、氏名・社員コード・共通パスワードは載せない。ヘッダーの欄は手書きで埋める
- 「効果」の利用開始・日付・エラー件数は空欄(数字が分かったら `SECTIONS["koka"]` に入れる)
- 文字の大きさは、4つの箱に収まるいちばん大きい値に自動で合わせる
- フォントは IPA Pゴシック(`fonts-ipafont-gothic`)を埋め込む

## 用語の統一(添削の青カッコ)

| 使う言葉 | 意味 | 使わない言葉 |
|---|---|---|
| 入力ミス | 書き間違い・書き漏れ・転記ミス | 漏れ・間違い・入力間違い・転記ミス |
| 見落とし | 確認する側が気づかないこと | — |
| 入力 | 人がアプリに行路番号を入れること | 選ぶ |
| 登録 | アプリが Google カレンダーに予定を書き込むこと | 入る |
| 確認 / ダブルチェック | ダブルチェックは「AI と人」の組み合わせだけ | 二重チェック・チェック |
| 終了点呼での次勤務確認 | — | 現在の終了点呼・既存の点呼確認・次勤務の確認 |
| 画像 | — | 写真 |
| 当直 | — | 内勤 |
| PIN / 共通パスワード | PIN はログインのたびに使う各自の4桁。共通パスワードは新規登録のときだけ | (提案書に注記を入れた) |

各項目は、ほかの箱に合わせて「○結論(見出し)→ 説明」の形にそろえた。
