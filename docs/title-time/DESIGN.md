# 予定の名前に時間を付ける(設計)

状態: **実装済み(2026-10-11)**。5章の4つは本人が決めた(2026-10-11)。migration は `20261011000000_title_time.sql`

公開リポジトリなので、カレンダーID・個人情報・マスタの実データは書かない。

## 1. やりたいこと

Googleカレンダーの終日の予定の名前(タイトル)に、時間を半角の括弧で付けられるようにする。

| | 今 | チェックを入れたとき |
|---|---|---|
| 泊 | `1` | `1(10:00)` |
| 日勤 | `25` | `25(10:15)`(出勤時間だけ) |
| 非番 | `〜` | `〜(9:00)`(退勤時間) |
| 休日(公休など) | `公休` | 変えない |

- メモは変えない(泊は出勤時間と泊地、日勤は「出勤〜退勤」、非番は退勤時間)
- 括弧の中の時間は **メモの1行目の先頭** から読む(手で書き換えた日はその時間。「10:00 早出」のように後ろに言葉があってもよい。2026-10-11 X2)。時間で始まらないメモ・24時以降は付けない
- 名前がもう「(10:00)」のような時間で終わっているとき(手入力で括弧まで書いた)は、二重に付けない(2026-10-11 X1)
- 全角で書いても `H:MM` の半角にそろえる

## 2. 設定

設定画面の「3.」に、出勤用と非番用の2つのチェックを足す(「2件で登録」が出勤・非番で別なのに合わせる)。

| チェック | 列(user_settings) | オフのとき |
|---|---|---|
| 出勤の予定の名前に出勤時間を付ける | `title_day_time boolean not null default false` | 番号だけ(今と同じ) |
| 非番の予定の名前に退勤時間を付ける | `title_offduty_time boolean not null default false` | 「〜」だけ(今と同じ) |

- 既定はオフ。次に登録する分から変わる
- 「2件で登録」と同時に使える。終日の予定の名前だけが変わり、時間の予定はそのまま

## 3. 対象

- 出勤: 勤務用の日勤・泊。マスタにない手入力の番号も日勤と同じ(`splitDayEvents` と同じ判定)。時間は先頭の時間(`titleTimeOf`)
- 非番: 自動の非番(kind=`offduty`)と手入力の非番(`isOffdutyTitle`)。時間は退勤時間(`titleTimeOf`。「8:30〜9:02」なら後ろ、先頭の「〜」も読む)
- 対象外: 休日用カレンダーの予定、「公休」「年休」など休みの手入力

## 5. 決めたこと(2026-10-11 本人)

1. チェックは出勤用と非番用に分ける
2. 日勤の括弧の中は出勤時間だけ
3. 括弧は半角
4. 非番は `〜(9:00)`
